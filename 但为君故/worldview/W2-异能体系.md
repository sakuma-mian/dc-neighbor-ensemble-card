## 设定说明（给人读）

**一句话**：异能不是天赋，是**执念在肉体上开的裂口**。觉醒必然源于强烈情绪、创伤或濒死时刻；能力形态映照觉醒者当时最深的执念，因此**每一项能力都是这个人伤口的外形**。

这也决定了本卡的玩法基调：能力不是奖励，而是**一种要付利息的贷款**。用得越多，代价越重。

**各卡角色的具体能力属各卡的角色层**（`cards/<卡名>/lorebooks/`），本文件只写**通用规则**——它对后续任何一张同伴卡同样适用。能力的具体命名、边界与代价是卡私有内容，不在本共享层列举。

## 条目 ENT-W02 · 异能体系总则

- **策略**：🟢 Conditional
- **关键词**：异能、觉醒、觉醒者、能力、力量、超能力、异类、登记、失控、过载
- **投递位置**：`position=1`（After Char Defs）
- **预算**：约 620 字（估算）
- **内容（模型可见）**：

```text
【异能体系总则】

一、本质
异能是执念在人体上形成的裂口，不是血统、不是科技、也不是可自由选择的技能。每个人的能力形态都映照其觉醒时刻最深的执念，因此能力几乎总是带着创伤的形状。

二、四档阶段（对应状态字段 `主控/觉醒阶段`）
1. 未觉醒：普通人。是否有潜力无法可靠预判。
2. 初醒：刚觉醒，不稳定。情绪波动时会误触发、指向失控、范围不可控。
3. 掌控：可主动调用，但输出与精度受当下状态影响（疲劳、情绪、伤病会削弱）。
4. 过载：强行突破能力边界后的失控态。表现为代价剧增、能力暴走、事后留下可见后遗症；过载中做出的行为同样计入暴露与后果。

三、能力的写法纪律（强制）
每一项能力都必须同时写明三件事，缺一不可：
- 能做到什么（具体、有限、可判定）；
- 做不到什么（明确边界，禁止留白式的"视情况而定"）；
- 使用要付什么代价。
禁止万能能力。禁止"因为能力特殊所以什么都能做到"。

四、使用与判定
- 能力分两类：**主动型**需要意图与专注才能发动（被偷袭、极度恐惧、失血过多时更难调用）；**常驻型**不需要发动、持续或半自动生效（例如让人记不住她、一眼看出破绽）。常驻型同样要付代价，按“产生了实际后果的事件”计。
- 能力**不制造资源、不凭空产生情感、不改变他人的认知内容**：它可以放大或掩盖已经存在的情绪，但不能让人无端喜欢上谁，也不能让人相信一件假事。
- 能力不替代选择：它只能放大使用者原本的意图，不能替使用者解决问题。
- 每次使用都要在叙述中留下代价的痕迹（体力、伤处、记忆、情绪、他人的注意）。

五、强度天花板
异能无法对抗规模化、组织化的现代力量（武装、监控、法律、舆论）。隐秘世界的生存依靠隐藏与周旋，而不是碾压。
```

## 条目 ENT-W03 · 觉醒与代价

- **策略**：🟢 Conditional
- **关键词**：觉醒、代价、反噬、副作用、失控、后遗症、消耗、撑不住
- **投递位置**：`position=1`（After Char Defs）
- **预算**：约 560 字（估算）
- **内容（模型可见）**：

```text
【觉醒与代价】

一、觉醒触发
- 强烈情绪、长期创伤累积到临界点，或濒死、极端恐惧的时刻触发。
- 觉醒瞬间**不可控**：能力会以使用者当时最深的执念为形状自己成形，本人往往事后才理解自己得到了什么。
- 首次觉醒几乎一定会造成暴露风险（现场失控、目击者、破坏痕迹）。

二、代价的三种形态（对应状态字段 `主控/代价`）
代价不是可选项，是使用异能的必然结果。每次使用累积代价，形态视能力而定，通常属于以下三类之一或混用：
1. 身体代价：疼痛、伤处恶化、短暂失明、失声、脱力、旧伤复发。
2. 记忆与情感代价：丢失某段记忆、对某人某物的感觉变淡、情绪变钝。
3. 外界代价：被目击、被记录、被组织注意、被普通人记住（推高 `主控/暴露度`）。

三、代价的呈现纪律（强制）
- 代价必须在**同一轮或紧接的叙事中**出现，不能拖到"以后有空再算"。
- 代价不得被轻易治疗或忽略；能缓解，不能抹掉。
- 代价累积到高位时，能力本身开始变得难以控制——这是走向过载的前兆。

四、越界与过载
- 进入过载只有两条路径：① 强行突破已写明的能力边界；② 代价已累积到 81–100 的危险区，仍然主动使用能力。
- 过载中代价剧增、能力暴走，事后留下可见后遗症，并回落一档。
- 过载不提供额外收益，只提供更多麻烦。

五、恢复
- 代价只能靠时间、休息、治疗与（必要时）他人介入来缓解；没有任何能力可以无代价地清除代价。
```

## 数值档位（已定 DEC-037）

数值**已拍板**，正式值写在 `ENT-V02-变量更新规则.md` §6–§8：主动型能力每次代价 +8～+15（初醒）／+3～+8（掌控）；常驻型按产生后果的事件 +3～+8；进入过载一次 +25～+40；充分休息一日 −5。暴露度 +10～+25／+3～+8／每三日 −2；好感单次 ±3～±10、重大至 ±15。

本文件**不重复这些数值**，也不再保留任何示例值（此前写的 “+5 / +10 / +20” 已作废）。
