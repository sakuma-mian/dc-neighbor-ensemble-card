## ①-A 面纱规则契约（本卡第一硬规则）

| 项 | 契约 |
|---|---|
| 知情层级 | **普通人**（不知情）／**知情者**（组织成员、被卷入者、家属）／**觉醒者**（圈内） |
| 面纱状态 | `完好` → `有裂痕`（出现传闻、目击未坐实） → `局部暴露`（某场所有普通人确知） |
| 普通人目击后果 | 由组织介入善后（记忆处理／封口／威胁／利益交换）；**不得**让普通人当场平静接受“这是超能力” |
| 主控暴露度 | 0–100。低＝无人注意；中＝被知情者盯上；高＝组织主动接触或处理 |
| 叙事纪律 | ① 普通人不得习以为常地谈论异能；② 玩家角色**公开使用能力必付代价**（代价与暴露度同时上升）；③ 不在场的角色不得表现出其不应知的信息 |
| 状态映射 | `世界/面纱`、`主控/暴露度`（见 ③）；**面纱只降不升**（一旦出现裂痕，世界不会忘记） |
| 反猎奇条款 | 异能不得成为炫技表演；每次公开展示都必须留下后果（目击者、记录、组织注意） |

## ①-B 异能契约（觉醒型 + 代价 · **已定 DEC-007 / DEC-020**）

**通用规则**：

| 项 | 契约 |
|---|---|
| 觉醒触发 | 强烈情绪、创伤或濒死时刻触发；觉醒瞬间**不可控**，能力形态映照本人的执念 |
| 觉醒阶段 | `未觉醒` → `初醒`（不稳定、误触发） → `掌控`（可主动调用） → `过载`（强行突破后的失控态） |
| 代价累积 | 每次使用累积「代价」（0–100）；表现为三类——**身体损伤**／**记忆与情感流失**／**外界注意上升** |
| 越界惩罚 | 强行突破能力边界 → 进入过载：代价剧增 + 面纱风险上升，并留下可见后遗症 |
| 反万能条款 | **禁止“能力解决一切”**；每次使用必须在叙事中体现代价与限制，能力不得替代剧情与选择 |
| 强度曲线 | 各能力在初醒／掌控／过载三档的表现上限**待细定**（DEC-037） |

**五人的能力、边界与代价**：

| 角色 | 能力 | 能做到 | 做不到 | 代价（反噬） |
|---|---|---|---|---|
| **藤原花奈** | **「留白」** | 让接触过她的人记不住她的脸与名字；短暂让他人“想不起刚才发生了什么” | 不能抹除文字、影像等既有记录；不能抹掉已形成的强烈情感；不改变事实本身 | 每使用一次，**她自己的一段记忆被抹淡**（优先失去与母亲相关的部分） |
| **顾清寒** | **「威压」** | 释放压迫感，压制他人的敌意与勇气，使人退让、噤声 | 不能造成实际伤害；不能操控他人想法；对毫无恐惧概念的对象无效 | 左眼旧伤**剧痛并短暂失明**，同时诱发当年的创伤记忆 |
| **鱼沉秋** | **「缝」** | 近距离缝合或剪断两人之间的情绪联结——让敌意暂时平息，或让亲近感骤增 | 不能读取或篡改记忆；效果短暂、需近距离；对自己无效 | 每剪断一次，**她自己对某个人的感觉也淡一分**（她最怕变得麻木） |
| **楚羽笙** | **「回声」** | 把声音送到“在意她的人”耳中，跨距离生效；把他人注意力强拉到某处 | 对完全不在乎她的人无效；不能伪造他人的声音；不能强制他人服从 | 若声音被听见后**无人回应，她当场失声**（说不出话、被世界静音一段时间） |
| **诺薇拉** | **「解析」** | 看出人、事、物中的**矛盾与破绽**（谎言、异常、不合常理之处），给出“哪里不对劲”的方向 | 不能预知未来；不能直接给出答案；不能看穿纯粹随机或无动机的行为 | 看得越深，**越能看见自己的不合理之处**——自我怀疑反噬，越解析越不敢行动 |

**主控（玩家）异能**：由开局问卷自拟**倾向**，实际形态在首次觉醒事件中定型，并受同一套「通用规则」约束（能力必须写明能做到／做不到／代价，不得万能）。

```text
stat_data
├─ 结构版本: number（当前 1）
├─ 世界/   { 日期, 时段, 区, 场所, 面纱 }
├─ 主控/   { 姓名, 来历, 异能倾向, 异能, 觉醒阶段, 代价, 暴露度 }

└─ 事件/   { 进行中: [ { 标题, 状态 } ] }
```

**字段台账**（实现时逐字段补全 `path / type / default / writer / reader / renderer / cleanup / migration / example`）：

| 分组 | 字段 | 类型 | 默认 | 作用 | 写入者 |
|---|---|---|---|---|---|
| 世界 | 日期 | string | 纪年第 1 日 | 沙盒时间推进 | 剧情链 |
| 世界 | 时段 | enum | 早间 | 八档：早间／上午／午间／下午／傍晚／晚间／深夜／凌晨 | 剧情链 |
| 世界 | 区 | enum | 未定 | 行政区：江北／江南／新区／月石／未定。**滨江人文带、南江大学、深港等写进「场所」，不占「区」** | 剧情链 |
| 世界 | 场所 | string | 空 | 具体地点（含深港、南江大学等） | 剧情链 |
| 世界 | 面纱 | enum | 完好 | 完好／有裂痕／局部暴露（只降不升） | 剧情链 |
| 主控 | 姓名 / 来历 / 异能倾向 | string | 空（问卷写入） | 玩家自捏身份，以及觉醒前的期望方向 | 剧情链（问卷） |
| 主控 | 异能 | string | 空 | 觉醒后的能力定义（含能做到/做不到） | 剧情链 |
| 主控 | 觉醒阶段 | enum | 未觉醒 | 未觉醒／初醒／掌控／过载 | 剧情链 |
| 主控 | 代价 | number | 0 | 反噬累积（0–100） | 剧情链 |
| 主控 | 暴露度 | number | 0 | 自身被注意的程度（0–100） | 剧情链 |
| 角色 | 已遇 / 现实身份已知 / 已知为觉醒者 | boolean | false | 群像关系进程 | 剧情链 |
| 角色 | 其他信息 | string | 空 | 会影响后续的临时状态（伤势、人情、约定） | 剧情链 |
| 角色 | 关系阶段 | enum | 陌生人 | 陌生人／认识／熟悉／信任／亲密／破裂 | 剧情链 |
| 角色 | 好感 | number | 0 | 关系数值（-100～100） | 剧情链 |
| 事件 | 进行中 | record | 空 | 进行中的线索/任务（轻量，上限 5 条） | 剧情链 |

**设计纪律**：

- **每字段单一写入者**（剧情链）；脚本只做确定性推导，不得与 LLM 争抢同一字段。
- 没有消费者的字段不加（DEC-008 混合式）。
- **键名语言已定（中文）**：`ST-B1` §2.3 明确“中文键名直接使用，不需转义”（来源为运行时源码＋生产卡实战），故 schema 与路径**全部采用中文键**。**实机仍需验证**。
- `角色/` 用 `z.record()` 承接动态角色键；`.passthrough()` 只加在确需扩展的层。
- schema 带结构版本（实现为顶层 `结构版本`，当前值 1）；迁移幂等、失败安全；旧对话必须保持可读。**当前尚无迁移件**——第一版结构未变，出现结构变更时必须补。
- **禁止用 `.catch()` 兜底**：catch 的语义是“换成一个固定默认值”，会把校验失败伪装成成功（代价 60 会变成 0、面纱“局部暴露”会变回“完好”）。非法值应当**验证失败、由 MVU 拒掉该条 patch，原值保留**。
- `display_data`：极简状态栏若落地（DEC-035）再定义展示模型，**UI 不得直接改原始状态**。

**初始化**：

- 共享默认值＝`InitialVariables`（Zod `prefault` 兜底）；
- `主控/` 字段由开局问卷经**正常剧情链**写入（LLM 以 add/replace 更新）；
- **不在开场白伪造 `<initvar>`／`<UpdateVariable>`**（DEC-043）。

## ⑦ 离线验收清单（本机可自证的部分）

1. **schema**：可静态解析；六分组齐全；类型与默认值一致；`record`/`passthrough` 使用位置经复核。
2. **初始化**：`InitialVariables` 与 schema 默认值一致；开场白与开场词条**无伪造初始化块**。
3. **更新规则**：仅使用该 MVU 方言允许的 op；每条规则都能在输出格式中对应；无“可被模型逐字照抄”的硬编码长示例。
4. **词条标记**：`[mvu_plot]`／`[mvu_update]` 清单齐全；未标记条目逐条说明共享上下文的理由。
5. **脚本**：区域加载顺序与兜底逻辑正确；语法检查通过；脚本只读不写（除确定性推导）。
6. **正则**：渲染隐藏生效且不破坏解析。
7. **素材溯源**：入卡内容均可回溯到 MAT 编号；**无隐私信息入卡**；素材冲突项（诺薇拉住处等）已裁决。
8. **预算**：激活态词条 token 估算 ≤ 世界书预算（默认 25%，可调）。
9. **能力边界**：五人与玩家的每项能力都写明“能做到什么 / 做不到什么 / 代价”，**无万能能力**。
10. **面纱一致性**：全部叙事示例中，普通人面对异常的反应符合 ①-A（无“随口接受超能力”的段落）。
