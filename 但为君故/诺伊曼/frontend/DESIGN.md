# 夜航档案 · 江雾留痕

视觉权威：用户已确认本任务的设计提案，继承既有青冷主题。人物页采用纵列选择器、主视觉、关系记事三栏；操作界面紧凑，场景页面舒展。访客在人物页沉浸体验，在状态页快速操作，在开场页描述身份。

第一屏：五人纵列，人物占据中央最大画面，真名与网名形成大小层次，右侧为关系和已知信息。页底收拢此刻状态。独特交互是以实际身份揭晓条件控制标题、画面与内容，而非只模糊文字。

底色 #060E12 / #0B161C，正文 #E4F1F4，次要字 #9FBAC2，强调 #5FD4E0；状态色沿用原项目。中文宋体标题配系统黑体正文。细线而非层层边框。素材本地保存，零运行时网络依赖。

动效只用于人物切换和面板进入，减少动态效果时取消。小屏单列与横向人物选择。所有表单、按钮、弹窗可键盘操作。此版本是可交互离线前端与可嵌入渲染源，不宣称酒馆宿主通过。
