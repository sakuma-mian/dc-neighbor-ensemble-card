# 但为君故 · 沉吟至今

夜航档案 · 江雾留痕 / 前端 v0.2

直接打开 `index.html` 即可浏览。`statusbar.html` 是独立紧凑状态栏。无需 npm、服务器或网络。上级目录的 `但为君故-离线前端.html` 是图片、样式和脚本全部内嵌的单文件版，可单独移动。

## 已实现

- 五人人物档案、按现实身份控制立绘和真名、独立觉醒者身份标记。
- 以零为中点的好感条、关系阶段、现况记事。
- 时间地点、面纱、代价、暴露度；紧凑状态栏可展开人物与线索。
- 开场四项问卷、会话内草稿保存、逐记录隔离、预览和复制发言。
- 四个城区公共索引；场景目前使用一幅原创南江氛围图，已标明非各区实景地图。
- 演示进度／初始状态切换、本地 JSON 导入、格式与状态校验、错误反馈。
- 桌面、窄容器、键盘操作、减少动态效果。

首次打开使用**演示存档**。其中进度、关系、记事是明确标注的虚构示例。点击右上角“演示存档”，选择“初入南江”可检查未知身份状态。源文件基线是仓库提交 `d0699d83466ad396f914fc32f22fc70d93ed941e`。

## 交付边界

这是完成离线交互检查的前端源码与预览，并非可直接导入的角色卡 JSON/PNG，也不是已接入酒馆的运行时脚本。现有卡的变量定义与 `render.js` 未被替换。

当前没有目标 SillyTavern、Tavern Helper、MVU 的安装版本与运行环境，因此未猜测宿主事件或自动发送 API。问卷交付真实发言文本，用户复制后通过酒馆正常输入发送；不伪造初始化，不自动觉醒，不修改正式状态。

## 自有渲染接口

以下为本项目定义并测试的接口，不是 SillyTavern API。宿主适配层取得正确聊天／楼层的 `stat_data` 后，把快照显式交给渲染器：

```js
const ui = NightArchive.mount(element, {
  snapshot: statData,
  contextId: 'stable-chat-id',
  floor: 12,
  assetBase: './assets/'
});

// 独立紧凑状态栏：增加 surface: 'status'
// 新快照不更改当前选中的人物；contextId 变化则清理上个聊天的选择。
ui.update(nextStatData, {contextId: 'stable-chat-id', floor: 13});
ui.unavailable('状态读取失败，请刷新记录。');
ui.getDraft(); // 返回当前草稿和开场消息文本，不发送
ui.destroy();  // 移除监听器、定时器与 DOM
```

引入顺序：`style.css` → `data.js` → `app.js`。多个挂载实例应放在独立 iframe 内，或由接入者提供独立文档作用域；本版不承诺同文档多实例弹窗 ID 隔离。

传入 `snapshot` 时不加载演示状态；不传快照也不指定 `mode:'demo'` 时显示“尚未收到状态数据”。接受 `stat_data` 本体或包含该字段的对象。结构版本必须是 1；非法数值或枚举明确报错，不用 0 或安全态掩盖。缺失单个角色显示“状态缺失”。布尔值的字符串 false 不会被反向识别为 true。

宿主适配待验：MVU 就绪路径、事件及卸载方式、聊天 ID、消息楼层与 swipe 绑定、iframe 生命周期、实际计算样式、真实开场消息发送与生成链。仅通过本地浏览器测试不代表这些项目通过。

## 信息边界

真实姓名与立绘仅在 `现实身份已知` 为真时进入展示 DOM。`已知为觉醒者` 只显示身份，不展开能力、登记和秘密。`已遇` 不被解释为目前在场。好感不推导关系阶段。`其他信息` 是剧情侧提供的当前可展示记事，其内容权限仍需由卡的生成规则保证。

城市索引不伪造探索率、地图坐标、角色位置和天气。全局面纱状态不解锁单人身份。源代码／资产文件本身包含角色定义，不提供加密或反查源防剧透能力。

## 素材

`assets/` 六幅图片由内置 image_gen 生成：五张人物概念立绘与一张南江场景。依据原仓库人物锚点，为本次前端设计制作；不代表原作者已确认的官方人设图。未下载或挪用《鸣潮》图片、字体、图标或前端代码。图标为本次编写的简单 SVG 路径；字体使用系统回退栈，无第三方字体包。

生成提示词见 `asset-prompts.json`。图片以原始 PNG 保存，未作像素编辑。全套资源约 14 MB，首版优先离线可携带；后续正式入卡时应结合区域加载和目标设备预算选择压缩与交付策略。

## 源码与再构建

可维护文件为 `source/data.js`、`source/app.js`、`source/style.css`、`assets/`。`build.cjs` 将这些内容打包成单文件 HTML，不引入构建依赖。单文件是生成物，改源码后执行 `node build.cjs`。

验证结果见 `verification.json`；预览图片见 `preview-desktop.png` 与 `preview-mobile.png`。所有结果限于离线 Chromium/Edge 浏览器。
