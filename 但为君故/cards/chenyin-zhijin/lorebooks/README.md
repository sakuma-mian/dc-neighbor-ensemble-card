## 为什么这一层要“改写”而不是“照抄”

素材是**旧卡**的人设（那套卡用“战争迷雾／知识矩阵”驱动，已随 DEC-004 废弃）。它们的**人设、背景、外貌、性格**按 DEC-005 保留，但有两处必须动：

1. **秘密的驱动方式变了**：旧稿的秘密靠“迷雾格 + 揭开条件”运转；本卡没有迷雾系统，秘密改为**靠关系阶段与代价累积自然浮出**（对应 `DEC-008` 混合式状态）。
2. **加入了异能**：每人要补上「能力能做到什么／做不到什么／代价」，并与人设的执念对齐（DEC-020）。

除此之外，**不得改动人设事实**（外貌、家庭、年份、关系、说话方式）。素材里没写的，就写「原文未写」，**不补编**。

## 投递策略（依 `ST-A3`）

| 项 | 取值 | 理由 |
|---|---|---|
| 策略 | 🟢 Conditional | 群像卡不可能五人常驻，否则预算必炸 |
| 关键词 | **网名 + 现实名 + 标志性称呼**（如 `佐久间眠、花奈、藤原`） | 线上/线下两种叫法都要能触发 |
| 投递位置 | `position=1`（After Char Defs） | 角色定义属稳定信息，不随对话深度移动 |
| 递归 | 允许（城区条目提及 → 角色条目可被带出）；角色条目自身设 Non-recursable | 防止五人互相链式全激活 |
| 中文设置 | **关闭 Match Whole Words** | `ST-A3` §4.3 |
| 单条预算 | 目标 600～800 字／人；**实际撰写为 880～900 字／人** | 五人同时在场约 **4,480 字**，超目标约 12%；**降级预案截至 2026-09-13 尚未执行**，待组装实测后决定 |

### 预算降级预案（重要）

**状态（2026-09-13）**：五条词条实际合计约 4,480 字，已越过上表目标 12%，**预案尚未执行**——按“先实测、后压缩”的次序，等组装阶段拿到真实 token 数据再决定是否降级，**不提前删内容**。

群像是本卡最贵的部分。若组装实测确认超预算，按此顺序降级，**不擅自删人设**：

1. 把每人的「背景时间线」「条件化行为」下沉为**独立子条目**（关键词更窄，只在相关场景激活）；
2. 把「攻略线」并入关系条目，改为按关系阶段触发；
3. 保留每人的**不可删三件套**：外貌锚点、说话方式、异能代价。

### 不投递给更新模型

角色词条属剧情侧，标 `[mvu_plot]`。更新模型只收变量规则、输出格式与当前状态（DEC-012），**不收角色人设**。
