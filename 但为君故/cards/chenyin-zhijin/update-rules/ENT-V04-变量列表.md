# ENT-V04 · 变量列表

> 层：变量层 ｜ 状态：**已定**（v0.2 依对抗审查修正，2026-09-13）
> 作用：让模型知道“有哪些变量、各是什么类型、取值范围是什么”；**实时取值**由 MVU 的当前状态注入承担，不在本条目重复

---

## 条目 ENT-V04（内容源）

- **条目名**：`变量列表`
- **策略**：🟢 Conditional（关键词：变量、状态、当前）
- **投递位置**：`position=1`（After Char Defs）
- **投递范围**：**共享上下文**——剧情模型与更新模型都需要知道变量结构；按双兼容基线**不加标记**，理由见下
- **预算**：约 520 字（估算）
- **内容（模型可见）**：

```text
【变量结构】

结构版本  数值  当前为 1

世界：
  日期  文本
  时段  枚举  早间 / 上午 / 午间 / 下午 / 傍晚 / 晚间 / 深夜 / 凌晨
  区    枚举  江北 / 江南 / 新区 / 月石 / 未定（区只到行政区一级）
  场所  文本  具体地点，含“深港·未登记层”“南江大学”“滨江人文带”等
  面纱  枚举  完好 / 有裂痕 / 局部暴露（只降不升）

主控：
  姓名      文本
  来历      文本
  异能倾向  文本  觉醒前的期望方向
  异能      文本  觉醒后定型，含“能做到 / 做不到 / 代价”
  觉醒阶段  枚举  未觉醒 / 初醒 / 掌控 / 过载
  代价      数值  0–100，反噬累积
  暴露度    数值  0–100，被普通人注意的程度

角色：动态集合，键为角色现实名
  已遇            布尔
  现实身份已知     布尔
  已知为觉醒者     布尔
  关系阶段        枚举  陌生人 / 认识 / 熟悉 / 信任 / 亲密 / 破裂
  好感            数值  -100 ～ 100
  其他信息        文本  会影响后续的临时状态

事件：
  进行中  数组，最多 5 条，每项含：标题（文本）、状态（未接 / 进行中 / 完成 / 失败）

说明：
- 上表只描述结构与取值域，当前的实际取值以注入的状态数据为准。
- 不要新增本表之外的顶层容器或路径。
```

## 未标记理由（按 TW 双兼容基线逐条说明）

| 投递对象 | 为什么需要看到 |
|---|---|
| 剧情模型 | 需要知道哪些状态会被记录、有哪些取值域，才不会写出与状态矛盾的情节（例如已经知道对方是觉醒者，却仍按“不知道”演） |
| 更新模型 | 需要知道路径与取值域，才能写出合法的 patch |

**代价评估**：约 520 字进入两侧上下文。若实测预算紧张，可把“事件”段并入更新规则条目，仅保留更新模型侧。

## 已知缺口（作者须知，不注入）

1. **“当前状态注入”尚无实现定义**：契约把“当前状态注入”列在更新模型侧，但全项目还没有条目或脚本承担“把 `stat_data` 实时取值交给模型”。可能的落点是 MVU 的 `[mvu_update]` 机制或 R1 脚本，**具体机制未经 `$sillytavern-api-reference` 与实机确认**，不得凭推测写死。
2. **`区` 的收敛说明**：原枚举含「滨江」，但滨江人文带属江南区、南江大学与深港是场所而非行政区，故一律移入 `场所`。此改动已同步 `zod_schema.js` 与 `ENT-V02`。
