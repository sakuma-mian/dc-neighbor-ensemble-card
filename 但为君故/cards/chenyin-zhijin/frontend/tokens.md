## 〇、定案说明（2026-09-13）

主题定为 **青冷**，依据两条独立证据：

1. 本产品线既有血脉是**青**（旧前端命名「雾青」，主色 `#8FD0D8`）；
2. 库洛/鸣潮入口页的像素统计显示**青为第一色族**（cyan 40.8%，绿 15.3%、蓝 12.1% 远低）。

**版权边界（重要）**：全程**未使用**该站任何图片、图标、插画或代码；只用业界**通用视觉手法**（斜切角、单色荧光、细描边、扫描线、高对比排版）自绘。整页外部资源数 = **0**。

> 另：该站的真实界面语言**无法从代码侧获取**（HTML 只有 SPA 外壳；CSS 是 `create-vue` 脚手架模板；2 MB 的 JS bundle 不含样式文本，样式为运行时按需加载）。因此青冷手法来自**通用设计语言**，不是对其界面的复刻。

## 一、设计原则

1. **HUD 优先可扫读，不做表演**：状态栏是每轮都要扫一眼的界面，装饰必须让位于信息密度；**装饰集中在群像档案页**。
2. **强调靠排版与几何，不靠加色**：字重、字距、细分隔线、斜切承担强调。
3. **状态三重编码**：颜色 + 文字 + 形状。**颜色永远不是唯一线索**。
4. **青只做装饰与标签，不做状态色**：状态色固定为绿／黄／红三色，避免“青=正常”与“青=强调”互相冒充。
5. **形与色分层**：结构层（斜切/内辉/扫描线）只作用于青冷主题；换主题时结构可保留或剥离。

## 二、色彩令牌（青冷 · 定案）

```css
/* 底与线 */
--nd-bg-deep:     #060E12;   /* 页面底 / overlay 背幕 */
--nd-bg-panel:    #0B161C;   /* 面板底 */
--nd-bg-raise:    #12222A;   /* 条槽 / 抬起块 */
--nd-line:        #1B323B;   /* 分隔线（1px） */
--nd-line-strong: #2A4E5A;   /* 框线（照片框等） */
--nd-line-soft:   #14262E;   /* 弱分隔 */

/* 文字 */
--nd-text:        #E4F1F4;   /* 主文字 · 冷白 */
--nd-text-dim:    #9FBAC2;   /* 次要文字 */
--nd-text-mute:   #6E8C95;   /* 弱字：仅面板底之上，不承载关键信息 */

/* 装饰主色（不做状态语义） */
--nd-cyan:        #5FD4E0;

/* 状态语义（唯一三个） */
--nd-safe:        #74C08A;   /* 正向 */
--nd-warn:        #D9A93C;   /* 注意 */
--nd-seal:        #E06055;   /* 危险 */
```

**对比度实测（对 `#0B161C`）**

| 令牌 | 实测 | 判定 |
|---|---|---|
| `--nd-text` | 15.87:1 | ✅ AAA |
| `--nd-text-dim` | 8.97:1 | ✅ AAA |
| `--nd-text-mute` | 5.10:1 | ✅ AA |
| `--nd-cyan` | 10.46:1 | ✅ AAA |
| `--nd-safe` | 8.42:1 | ✅ AAA |
| `--nd-warn` | 8.46:1 | ✅ AAA |
| `--nd-seal` | 5.21:1 | ✅ AA |

**⚠ 强制约束**：`--nd-safe`(#74C08A) 与 `--nd-warn`(#D9A93C) 的明度比为 **1.00:1（完全相同）**；`cyan` 与 `safe` 为 1.24:1。这是“青冷底 + 三状态色”约束下的必然结果，**无法靠调色消除**。因此：

> **状态必须同时给出文字与形状**（档位文字如「轻微／明显／严重／危险」、形状 `○ ◪ ■ □`）。任何仅以颜色区分状态的实现都属缺陷。

## 三、结构层（青冷专用）

| 手法 | 实现 | 作用范围 |
|---|---|---|
| **斜切角** | `clip-path: polygon(0 0, calc(100% - 12px) 0, 100% 12px, 100% 100%, 12px 100%, 0 calc(100% - 12px))` | 面板、五人条、跳板卡 |
| **内描边 + 内压暗** | `inset 0 0 0 1px rgba(95,212,224,.12)` + `inset 0 2px 12px rgba(6,14,18,.55)` | 同上 |
| **扫描线** | 横线每 4px 一条，青 6% 透明 | **仅档案页**（状态栏不加，避免影响扫读） |
| **细网格** | 竖横各每 9px 一条，青 2% 透明 | 面板底 |
| **噪点** | 内联 SVG `feTurbulence`，整体 5% | 档案页背景 |
| **面纱斜线遮罩** | `repeating-linear-gradient(135deg, …)` | 面纱状态格 |

**为什么斜切不能配外发光**：`clip-path` 会裁掉元素外侧的 `box-shadow`，外发光必须改用伪元素或 `filter: drop-shadow`（后者创建新层叠上下文，HUD 上慎用）。本方案**不加外发光**，改用内描边表达“嵌在底板上”。

## 四、排版、间距与构件

```css
--nd-font: "Microsoft YaHei", "PingFang SC", "Noto Sans CJK SC", system-ui, sans-serif;
--nd-fs-xl: 17px; --nd-fs-lg: 15px; --nd-fs-md: 13px; --nd-fs-sm: 12px; --nd-fs-xs: 11px;
--nd-lh: 1.75; --nd-ls-label: .18em; --nd-ls-name: .08em;
--nd-num: tabular-nums;                      /* 数字一律等宽对齐 */
--nd-sp-1: 4px; --nd-sp-2: 8px; --nd-sp-3: 12px; --nd-sp-4: 16px; --nd-sp-5: 22px;
--nd-panel-w: 680px; --nd-overlay-w: 1080px; --nd-bar-h: 5px; --nd-tap: 44px;
```

| 构件 | 规格 |
|---|---|
| `nd-panel` / `nd-card` | 底 `--nd-bg-panel` + 细网格；左 **2–3px 状态条**；上边 1px `--nd-line`；斜切角；**不叠双层边框** |
| `nd-label` | `11px` + `0.18em` 字距 + `--nd-text-dim`；可带一枚 Lucide 图标（`--nd-cyan`） |
| `nd-bar` | 槽 `--nd-bg-raise`，高 5px，**每 25% 一道刻度**；必须紧跟数值与档位文字 |
| `nd-tag` | 1px 描边 + 11px 字；用于二元状态（身份已知／未揭晓、在册／未登记） |
| `nd-shape` | CSS 生成：`□` 正常、`◪` 注意、`■` 危险、`○` 正向 —— **不用 emoji** |
| `nd-stamp` | 印章标记（1.5px 描边 + 内缩 3px + 旋转 3.5°），用于面纱等世界级状态 |
| `nd-face` | 照片框 44×52，内缩阴影；无图时显示姓氏字 |

## 五、状态语义映射（三重编码）

**代价 / 暴露度（0–100）**

| 区间 | 文字（必显） | 色 | 形状 |
|---|---|---|---|
| 0–20 | 轻微 | `safe` | `○` |
| 21–50 | 明显 | `warn` | `◪` |
| 51–80 | 严重 | `warn` | `◪` |
| 81–100 | **危险** | `seal` | `■` |

**面纱（只降不升）**：`完好` / `有裂痕` / `局部暴露` —— 必显全称，配 `□ ◪ ■` 与斜线遮罩。

**关系阶段（六档）**：`陌生人 / 认识 / 熟悉 / 信任 / 亲密 / 破裂` —— 文字为主；`信任` 及以上用 `safe`、`破裂` 用 `seal`，其余 `text-dim`。

**面具状态（四态，取代旧卡的迷雾珠）**：`未相遇 / 已相遇 / 身份已知 / 觉醒者已知`；**两者都知道时并列两个徽记，不合并**。

## 七、动效与降级

- 动效只用于状态确认（跳板卡 hover、数值条过渡 150ms）；**不做循环动画与光效**。
- 必须尊重 `prefers-reduced-motion: reduce`。
- 不用 `backdrop-filter` 作为唯一手段；不用 `100vh` 作为唯一高度策略。
