# 角色模板（核心群像用）

> **谁填这个**：驾驶员（你）。Agent 不替你写内容，只负责机制接口与一致性检查。
> **怎么用**：复制本文件，改名成角色名，逐项填写。**留空是可以的**，标了"（可后补）"的项等角色创建页定完再补。
> **为什么是这些字段**：它们不是格式规定，是从第 1~2 阶已冻结的 12 条施工条款**反推出来的最低必要信息**——缺哪项，后面的机制就接不上。

## 一、基础信息

| 字段 | 你的填写 | 为什么要它 |
|---|---|---|
| **真名** | | 给玩家查证的锚点 |
| **圈内代号** | | 「别人以为他是谁」——会骗人的那层信息 |
| 所属势力 | 管理局 / 血统家族 / 散人网 / 不属于任何一方 | 决定他站在哪儿 |
| 势力内部立场 | 守规则派 / 讲结果派 / 守旧派 / 求变派 / 保命派 / 反抗派 / 中立 | 决定他跟谁对立 |

| 年龄段 | | 影响圈内资历与人脉厚度 |

## 二、机制层（这几项最终会变成 MVU 变量，请尽量填）

| 字段 | 你的填写 | 说明 |
|---|---|---|
| **觉醒刺激** | | 他经历过什么才点的火。**这是灰色基调的来源**——最优秀的异能者往往是被毁得最彻底的那个 |
| **能力本质** | | 觉醒后固定的那个能力。**一经确定不再改变**（可以提升用法与规模，不会变成另一个能力） |
| 能力的用法 | | 他惯用怎么打、怎么用 |
| 能力的限制 | | 什么情况下没用 / 会失效 |
| **代价的具体表现** | | 用能力时他身上会发生什么（内在损耗） |
| 暴露特征 | | 他出手时，别的异能者感应到的是什么感觉（同类感应，见 C-09） |
| **位阶** | | 圈内大致的强弱位置 |
| **是否藏级** | 是 / 否 | 他愿不愿意让人知道真实水平。**藏级是常规手段**，不是特例 |
| 是否走"异化"路线 | 是 / 否 / 未定 | 极少数人让能力发生质变的危险路线 |

## 三、博弈层（这一层决定他是不是活人）

| 字段 | 你的填写 | 说明 |
|---|---|---|
| **目标** | | 他想要什么。**必须一句话能说清** |
| **底牌** | | 别人不知道的那件事 |
| **旧账** | | 跟谁有什么过节或交情（写清是第几号角色） |
| **不可原谅的事** | | 他手上那件真的脏的事。**每个 NPC 都必须有** |
| 站得住的理由 | | 他为什么这么做，玩家听完能理解。**每个 NPC 都必须有** |
| 弱点 / 把柄 | | 玩家能拿住他的东西 |
| 手上握着的资源 | | 他能给出什么好处（情报 / 门路 / 钱 / 庇护 / 战力） |

## 一致性检查清单（填完自查，或交给我检查）

逐条对照第 1~2 阶已冻结条款：

- [ ] **C-01**：他的存在不破坏"异能对大众隐瞒"这个前提
- [ ] **C-03**：他属于城市里那几百人之一，不是随机路人
- [ ] **C-04**：他的能力来自血统天赋 + 觉醒刺激，两者都说得清
- [ ] **C-05**：不能仅凭血统认出他的身份（除非剧情明确他自曝）
- [ ] **C-06**：他的能力本质固定；成长走"掌控度/承载上限"或"异化"两路之一
- [ ] **C-07**：他有内在代价 + 暴露风险，且**力量越大越藏不住**
- [ ] **C-08**：他的位阶信息是"传闻"，不是可查证的权威数据
- [ ] **C-09**：他出手会被其他异能者感知（强者能感知弱者，反之不行）
- [ ] **C-10**：他有"站得住的理由"**且**有"不可原谅的事"
- [ ] **C-11**：本设定不含物理痕迹（不会被摄像头/仪器拍到）
- [ ] **D-019**：他明确属于四大块之一（管理局 / 家族 / 散人网 / 不属于任何一方）
- [ ] **D-022**：若属管理局，注意机构是半官方、内部有人牟利
- [ ] **D-025**：若属家族，注明是三大族之一还是那个没落旧家
- [ ] **D-026**：他有真名，也有圈内代号
