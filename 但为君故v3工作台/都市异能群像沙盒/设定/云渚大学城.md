# 云渚大学城（云渚区 · 北部片区）

> **定位**：南江市云渚区内部的一个片区设定。它是**藤原花奈主线剧情的发生地**。
> **配套**：`设定/南江市·城市志.md`（六区正文）｜`设定/城市模板.md`（六格速查表）｜`设定/藤原花奈.txt`（核心群像第 01 号）
> **主创**：驾驶员 ｜ **记录整理与一致性核验**：Agent
> **建档**：2026-09-16（第 06 阶 · 核心城市建设续）
> **口径**：遵循全架空——本文件出现的所有地名均为自造，不使用任何真实地名。
> 命名法：城市与片区名一律从"水"里长出来（三点水同族）；自然水体允许与不知名小湖重名，但不撞知名湖泊与行政区。

# 一、这是什么地方

**【位置】** 云渚区北部，绕着云渚湖摊开。西面是西屏山，东南不远是泾口镇水乡古镇。到市中心澜浦要换两次地铁，**一小时车程**。

这一小时是全篇最重要的一句设定。它同时解释了四件事：为什么管理局管得松、为什么散人网敢在这藏、为什么藤原花奈能在这里同时当学生和掮客、以及为什么这片地方的麻烦从来不是"外面的人找上门来了"，而是"里面的人自己不见了"。

**【规模】** 师生合计十几万。几所高校沿湖分布，校区之间用绿道、共享图书馆与共享实验平台连起来。加上校区商业、家属区与租房市场，形成一个**独立于市区的生活圈**——住在这片的人，可以几个月不进一次城。

**【气质】** 干净、年轻、过渡。这里的人大多只待四年，行李箱永远没收起来过。湖边永远有人在跑步，也永远有人在打电话谈一个还没落地的机会。

**【它在南江市的位置】** 云渚区是全市高校资源最密集、山水条件最突出的区域（见城市志）；大学城是云渚区的北部片区，也是整个云渚"知识生产"那一面的实体。云渚区的另一面——湖心岛、无主宅院、封闭疗养院旧址构成的"合理空旷"——在湖的西侧与南侧，与大学城**贴着但不重叠**：一个在明处运转，一个在暗处空着。

# 二、片区怎么分（六块）

| 片区 | 位置 | 是什么 |
|---|---|---|
| **湖东 · 西屏大学老校区** | 云渚湖东岸 | 老牌综合大学。红砖老楼、老馆、文学院、校医院、体育中心都在这。**藤原花奈在这片活动** |
| **湖西 · 理工与应用学科组团** | 云渚湖西岸 | 云渚理工大学与几个研究所。新楼、实验室、共享实验平台、产学研园 |
| **湖北 · 医学校区** | 云渚湖北岸 | 南江医科大学云渚校区与附属医院——全片医疗资源最全的地方 |
| **学生街与书市** | 紧贴西屏大学北门 | 校区之间那条街：吃的、租房的、打印店、快递站、理发店、旧书店。**零号房在书市最末一家** |
| **绿道环线** | 绕湖一周 | 连接各校区的步行与骑行道。夜里没什么人——路灯间隔大、施工段多、监控有缺口 |
| **云渚湖** | 全区中心 | 湖本身。湖西岸有封闭疗养院旧址，湖心岛与无主宅院群是散人网的藏身处（见城市志） |

**为什么学生街必须紧贴老校区北门**：这是机制约束，不是景观安排。藤原花奈操控假体时，本体必须待在**同一街区（几百米以内）**。学生街贴着北门，书市在学生街最末端——从零号房后间到她的教室，步行不超过十五分钟。**这片地方是她唯一能边当学生边做生意的地方**：再远，她的能力就用不上了。

# 四、藤原楼与藤原奖学金

> 这两样是"藤原"这个姓在大学城里留下的痕迹。它们不是背景，是**每天都要面对的刺**。

## 藤原楼

西屏大学文学院的一栋老楼，红砖、四层、木楼梯。当年家族风光时捐建，牌匾至今挂在门楣上。

**现在它的用途**：文献与档案学系的教学楼。

**也就是说——藤原花奈每天从自己家的名字下面走进去上课。**

这是她处境的实体化：她能切割与家族的关系，切不掉这个姓写在石头上的部分。而这栋楼给了她一个**完全正当的理由**每天待在里面——上课、查资料、进旧刊室。

## 藤原奖学金

当年设立的捐赠奖学金。家族垮了之后，这笔钱**停了又没停干净**：本金没了，学校用基金利息继续撑，每年还在评、还在发。

于是它变成了校园里一个尴尬的存在：

- 知道来历的老教师不提它，新学生以为那只是个普通的企业奖学金
- 而**没有一个藤原家的人来领过**
- 而全校唯一一个姓藤原、且年年够格的人，就在这栋楼里上课

> **留给剧情的口子（不预设她的选择）**：她领不领、为什么领或不领，是她自己的事。这个设定只负责把问题摆在她面前，每年一次。

# 五、日常层：学生的城市

- **时间表管着一切**：课表、考试周、开题、答辩、毕业季。想在这片地方长期待着，就必须有一个身份，而身份自带作息。
- **每年两季大换血**：九月入学潮、六月毕业潮。整片地方的常住面孔四年一换。
- **学生街的生意**：吃、住、打印、快递、理发、旧书。都是刚需，都很小，都不起眼。
- **书市**：学生街最末端的一小片，十几家旧书店、旧物摊、收旧书的。学期初最热闹，学期末最乱——**毕业的人什么都卖**。
- **图书馆占座文化**：自习室的书包、水杯、一本摊开的书，就是一次"这位置有人"的声明。
- **绿道与湖边**：白天跑步的人多，夜里几乎没人。
- **校医院与体育中心**：日常人流不大，但永远有零星的、独自来的人。

# 六、暗面层：全城最干净的擦痕现场

> 云渚区整体的暗面是"合理空旷"（见城市志）。大学城的暗面不同——**它不是空，是人太多、流动太快。**

## 1. 一个人从这套系统里消失，不会有第二次追问

每年几万人进出：新生、毕业生、留学生、访问学者、交换生、延毕的人。

一个人要"消失"，这里有太多合法出口：**退学、转学、休学、出国、延毕、换导师、去外地实习**。每一条都是正常手续，每一条都不需要解释。

> 在澜浦，一个人不见了会有人问；在沧湾，整个家属院都会知道。**在这里，没有人会问第二次。**

这是全城最干净的擦痕现场。所以它对散人网有吸引力，对一个掮客更是。

## 2. 灰色经济：全都是"说得通的交易"

代写、保研名额、实验数据、校外租房的二房东、留学中介、论文挂名、名额置换。

每一笔单独看都不算犯罪，每一笔都需要一个"中间人"。**这是掮客的温床**——而这片地方的人普遍认为"找关系办事"是常识，不是丑闻。

## 3. 导师的权力

一个学生能不能毕业，取决于一个人。这是校园版的黑箱：不需要暴力，不需要组织，只需要一封信。

## 4. 说不清的研究

学校里真有人在研究说不清的东西——民俗学、心理学、社会学，收着一堆都市传说、目击者报告、口述史。

**最接近真相的人，永远差一步。**

（这一条严格守住 C-01：他们研究的是"民俗"和"心理现象"，没有人研究异能，也没有人接近答案。）

# 七、圈内层：为什么管理局不在这片

**管理局在云渚的据点最小。** 原因很实在：

- 这里没有家族地盘（三大族在澜浦、沧湾、汐港；没落旧家缩在澜浦后巷）
- 这里没有黑市（黑市在汐港十六号保税仓）
- 这里没有高价值目标，离中心一小时
- 大学城自有一套秩序：**校方安保、导师权力、学生圈子**——这套秩序不认管理局的账，但也不跟它作对

结论：**这里不是无人看管，是没人重点看管。** 这正是它被需要的原因。

**谁在这片活动**：

| 势力 | 在这片的存在 |
|---|---|
| 管理局 | 最薄的覆盖。可能有一个挂着研究所名义的联络点，也可能连这个都没有 |
| 三大族 | 没有地盘。但**藤原家会派人来**——因为藤原花奈在这 |
| 散人网 | 藏身处就在同一个区的湖心岛；大学城是他们最常来"办事"的地方 |
| 圈内个体 | 学生、教职、后勤、周边商户里散着极少数人，互不相认 |

# 八、藤原花奈在这片地方的落点

> 以下每一条都与 `设定/藤原花奈.txt` 已定的机制逐条咬合。

## 身份

- **就读**：西屏大学 文学院 · 文献与档案学系（古典文献方向）
- **她在学什么**：物的来历——版本、纸张、印鉴、批注、流转。一件东西从谁手上到了谁手上，中间过了几道手。
- **为什么这个专业与她严丝合缝**：她的能力「镜皇之目」靠的也是**物的来历**——血、随身物、头发。**她学的是"物的来历"，她的能力靠的也是"物的来历"；学识与能力是同一件事的两种形态。**
- **对她处境的加成**：文献学给了她三样正当理由——**留在老楼里、翻别人的旧物、长期出入旧书店**。这三样同时是她上课、取物和开店的理由。

## 零号房（副业与据点）

- **位置**：学生街最末端的书市，最后一家旧书店
- **门牌 0 号的由来**：那一排房子是后来加盖的，编号的时候插不进去，就给了个 0 号
  · **这一点和代号是同一个逻辑**：她的名号「第零天使」由地点派生，而"零号房"这个名字也不是她起的，是**地址给的**
- **为什么开在这能成立**（对应她人设里三个悬着的问题）：
  1. **"客流最少、最安静，亏本也说得通"**——旧书店开在大学旁边，这件事本来就说得通，不需要解释
  2. **"她白天有课，店只在没课时开"**——大学城给了她天然的营业时间表；"难约"反而抬高她的分量
  3. **"操控假体时本体受限"**——零号房到教室步行十五分钟，全在她的操控范围内
- **取物接口**：**书市就是收旧物的地方。** 学生来卖旧书，书里夹着借书卡、一张照片、一根头发——每一样都说得通。她收素材的正当理由不需要编。

## 两个藏本体点

操控期间她几乎动不了，必须能锁门待几小时且无人来找。

| 优先级 | 地点 | 理由 |
|---|---|---|
| 首选 | **零号房后间** | 她完全掌控的空间：藏本体、存素材、安全见人都在这里 |
| 备份 | **西屏大学老馆的旧刊室** | 紧邻藤原楼，三层以上是闭架书库与旧刊室，学生基本不去、有锁、一待一下午。文献学专业的正当去处 |

> 一处刻意的对照：**一栋挂着她家姓氏的楼（藤原楼），隔壁就是一栋藏着她秘密的楼（老馆旧刊室）。**

## 取物点

| 要什么 | 去哪 | 为什么说得通 |
|---|---|---|
| 随身物（最常用） | 书市、自习室占座的物品、体育中心的公共更衣室 | 收旧物是她的专业与生意。**口径限定（v1.1 补）**：更衣室指公共更衣室，她只去捡落下的东西，本人不参与运动 |
| 血 | 西屏大学校医院、南医大附属医院、体育中心的医务点 | 学生看病、运动受伤都是常事。**口径限定（v1.1 补）**：她只去「收」，不参与任何运动——**游泳馆已从她的取物点里除名**（一个爬三层楼要在楼道歇一次的人出现在游泳馆，会立刻被人记住）。她的身体限制同时是她的纪律：**只去「她出现在那里不奇怪」的地方。** |
| 头发 | 宿舍区、学生街的理发店 | 日常场所。**同上口径**：都是她「出现得自然」的地方 |

## 风险点

- **校园人最密、眼睛最多**：一次出手比在别处危险得多
- **操控期间本体半瘫最难藏**：她只能靠生病、翘课、独处来遮——这在有课表、有点名、有同班同学的地方，是每天都要处理的问题
- **她的招牌就是她的把柄**：零号房是她身上唯一没有污点的东西，信誉一崩店就没了
- **家族会来**：藤原楼挂在那儿，她的名字在学籍系统里，家族不需要打听就知道她在哪

# 九、留给主线的接口

> 以下三条**不是新加的设定**，是已经存在的东西正好能接上。用不用、怎么用，归驾驶员。

1. **藤原家老宅（澜浦后巷六号院）两周前挂牌待售了。** 而她的目标是"把父母拿回来——遗体、遗物，或者一个名分"。那栋房子里可能就有她要的东西。这是现成的主线引擎。
   · 注意这是**跨区牵引**：事情在澜浦，人在云渚，她的一小时车程和几百米操控范围都会成为阻力。
2. **那个替她背锅的人，人还在圈里。** 如果他在同一座城市、甚至同一所大学，她的学生身份会立刻从掩护变成软肋。
3. **每年一次的问题**：藤原奖学金还在发，而全校唯一够格的藤原家人就在那栋楼里上课。她领不领，是一个每年都会回来的选择。
