# 顾清寒生活圈（棋盘新城 · 学后街 · 过江线）

> **定位**：南江市跨区的一条生活带——**核心群像第 02 号顾清寒的落脚点**。对应她人设文件「待补清单」第 3 条。
> **配套**：`设定/顾清寒.txt`（人设）｜`设定/南江市·城市志.md`（六区正文）｜`设定/城市模板.md`（六格速查表）｜`设定/云渚大学城.md`（她的旧梦所在）
> **主创**：驾驶员 ｜ **记录整理与一致性核验**：Agent
> **建档**：2026-09-17（第 06 阶城建续 · 第 02 号角色配套）
> **口径**：遵循全架空——本地名均为自造，不使用真实地名。

# 一、这是什么：一条线，不是一片地方

云渚大学城是**一片地方**——几百米内什么都齐（校区、店、藏身点全在一个街区）。
**顾清寒的生活圈是一条线。** 她每天在这条线上来回两趟，**四小时在路上**：

```
棋盘新城（家 · 潮川区）── 过江 ──▶ 南江一中（学校 · 澜浦区）──▶ 学后街（她真正的地盘）
```

这三个点之间没有中间地带。**她的生活不是被分成三块，是被剪成两半**：

| 半边 | 是什么 |
|---|---|
| **新城那边** | 父母买的房子。新的、干净的、没有生活痕迹 |
| **老城那边** | 她实际在过的日子。旧的、挤的、到处是缝 |

这一条线的形状决定了她的全部时间结构：**白天属于学校，傍晚属于那条巷子，夜里属于过江的地铁，睡眠属于新城。**

# 二、棋盘新城（潮川区 · 西侧靠江）

## 它是怎么来的

潮川区的**住宅组团**，不在金融城、科学城那几块。它坐落在潮川靠江的一侧，离过江线近——这是她每天能走通那条通勤线的前提。

千禧年初她父母来南江打拼，2015 年前后新城开发，他们搭上第一班车在这儿买了房。（**注**：原稿写的是"南江新区开发"，南江新区已改名**潮川区**，此处已按现名统一。）

## 名字的由来：它按棋盘格规划

横平竖直的街道，按格编号的组团。所以叫**棋盘**。

然后是那个反讽：

> **规划得最理性，住起来最记不住。**

她家是**三区 7 栋**。隔壁是三区 7 号院，再过去是 C-7 街区，小区名字全叫某某苑。

**三套编号系统并行，谁也不认识谁。** 她说"到现在都说不清自己住哪栋，全靠导航"——**那不是她记性差，是那地方真的长一样。**

## 配套

新建的、齐全的、标准化的：地铁站、商场、连锁店、社区公园、新学校、社区卫生中心。**什么都不缺，就是没有一段共同的记忆。**

（这与城市志对潮川区的判断完全一致：「缺少真正沉淀下来的共同记忆……许多人在这里工作、租房、恋爱、搬家，却始终觉得自己只是暂住」。棋盘新城就是这句话的实体。）

## 那间空房子（她的家）

**不是没人住的空，是没人生活过的空。**

- 家具是成套的、新的、没被用旧过
- 冰箱里有东西，但大多是过期的（父母偶尔回来塞一次，然后走很久）
- 阳台上常年没有晾着的衣服
- 她的房间整洁得不像有人住——因为她每天只有睡觉那几个小时在那儿

> **她真正的生活痕迹，全在老城学后街的那条巷子里。**

**这一条是她的处境在城建上的写法**：她有房子，但没有地方。她想要的是"一个能待着的地方"，而那个"地方"不在她家。

# 三、南江一中与学后街（澜浦区 · 北片）

## 位置

澜浦区**北片**的老公房带——不是西堤、长街、梧桐街区那些商业与历史核心。

> **一条要记死的隔离线**：藤原家的老宅**后巷六号院在澜浦南片**，学后街在**北片**。两条线在物理上就隔开，前期不该有交集。

## 学区带

两三条街里挤着：**南江一中**（市重点高中）、**实验学校**（含初中部，她初中在这里）、一所职校、两三所初中。

周围是上世纪的老公房、巷子、小卖部、文具店、打印店、五元店、修车摊、废品回收，外加满墙的补习班招牌。

**这是典型的旧学区带**：老、挤、有烟火，人也杂。谁都忙着活下去，**没人会多看她一眼**。

## 学后街（她真正的地盘）

这几所学校共同的后街。正式名叫**学后街**，学生嘴里就叫"学后"。

**她的地盘不是她现在就读的学校旁边，是她初中那所学校旁边。** 这就是人设里"地盘没换"那句话的物理版本——她放学不往新城的家走，先拐进这条巷子。

### 她的三个固定点

| 地点 | 是什么 | 为什么重要 |
|---|---|---|
| **巷尾小卖部** | 老板有一本赊账本，上面记着她的名字 | **她生活里唯一一个长期记得她的成年人** |
| **「二楼」** | 一栋老楼二层的网吧。楼梯口一块褪色灯箱，招牌上只有"网吧"两个字，常客就用楼层叫它 | **离校门两分钟、包夜便宜、而且不问任何问题。** 她在这儿有固定机位 |
| **南江一中** | 她的学校 | 那是"必须去的地方"，不是"她的地方"。**这两者她分得很清楚** |

## 南江一中：那栋楼里住着"沉默之前的她"

南江一中是市重点。**而她是靠自己考进去的。**

（她父母那套"学区房"买在潮川棋盘新城，帮不上她进澜浦的市重点——所以那个分数是她自己考的。）

> **这所学校是她身上最疼的一处证据**：能考进市重点的人，不是混子。
> 成绩榜上她一路下滑的名次、班主任那句"你本来可以"、贴在公告栏上的云渚理工大学介绍——
> **"沉默之前的她"就住在这栋楼里，每天跟她一起上学。**

这也是她为什么总坐光线暗的那一侧：教室靠窗那一列是留给"好学生"的位置，而她早就不坐了。

# 四、过江线：把两半缝起来的那条线

| 项 | 内容 |
|---|---|
| **澜川大桥** | 车行过江大桥（名字由澜浦＋潮川合成）。早晚高峰堵成停车场——**她坐不起车** |
| **轨交 4 号线** | 本地人叫"过江线"。**她坐这条**。学生卡半价 |
| **单程** | 约一小时：走到站 + 过江 + 换乘 + 走 |

## 高三的时间表，和它的代价

```
05:30  出门
07:00  早读
21:30  晚自习放
22:30  到家
23:00  睡
```

**每天四小时在路上。**

- 地铁上她总靠车厢连接处，坐光线暗的一侧，闭着眼——**地铁是她唯一能睡够的地方**
- **末班地铁才是她真正的门禁。** 不是电话，因为没人会打
- 这解释了她为什么放学不回家：**回家也是一小时，回去也是空房子。**

# 五、一条要记死的机制：老城的缝只对"人"有效，对"感应"无效

城市模板定了「**分层秩序**」——澜浦是核心区，监控最密、秩序最昂贵。而她的地盘恰恰在澜浦。

表面看这是矛盾的。真实城市里它是这样解的：

> **新城的监控是全覆盖的、标准化的、互相联通的；老城的监控是补丁式的、业主自装的、互不联通的。**
>
> 所以——**新城看起来更现代，其实更无处可藏；老城看起来密，其实到处是缝**：巷子、楼道、老公房的天井、店铺后间、老楼的夹层、黑网吧的二楼。

**但是——这里必须补一句，否则会写出硬伤：**

> **那些"缝"只挡摄像头和人眼，挡不住同类感应。**
>
> C-09 的感应是圈内雷达，它不看摄像头、不看巷子、不看有没有人。
> **只要她出手，附近有别的异能者，对方就会读到——不管她在多么隐蔽的巷子里。**

所以：

| 场景 | 老城的缝有效吗 |
|---|---|
| 逃课、躲在网吧、半夜在巷子里走 | ✅ 有效 |
| **动用「反伤」** | ❌ **完全无效**——唯一的办法是附近真的没有同类 |

**这条同时解释了她为什么五年没被发现：不是因为她藏得好，是因为她从来没出过手。**（她一旦出手，这个真空立刻结束。）

# 六、她已经成年了，但能去的地方全城不到十个

**先把一件事说清楚：她 18 岁了。法律上她哪儿都能去。**

| 门 | 开还是关 | 为什么 |
|---|---|---|
| **法律** | ✅ **开着** | 她成年了。没人能拿身份证拦她，深夜在外也没人能管她 |
| **钱** | ❌ 关着 | 奶茶、电影、商场跟她无关。她的娱乐是网吧包夜和小卖部赊账 |
| **时间** | ❌ 关着 | 早读、晚自习、点名、班主任的视线；请假要家长签字，而她家长在外地 |
| **路** | ❌ 关着 | 末班地铁就是她的门禁——不是别人给的，是赶不上就得想办法走两小时 |
| **家** | ❌ 关着 | 没有可以在出事时打电话的人 |

**结论：她的全城可用空间不到十个点，而且这些点全挤在同一条线上。**

**这比"被管着"更冷一层**：没有人拦她，也没有人等她。她随时可以去任何地方，只是没有钱、没有时间、也没有一个会问她"你怎么还没回来"的人。

> **关于「二楼」**：它不查身份证，但那从来不是她选它的理由——她本来就能进正规网吧。
> 她选它，是因为**离校门两分钟、包夜便宜、而且不问任何问题**。

## 与花奈的对照

| | 活动半径 | 内容密度 | 为什么 |
|---|---|---|---|
| **藤原花奈** | **小**（几百米） | 极密 | 被迫——本体必须在假体附近几百米内 |
| **顾清寒** | **大**（几十公里） | 极稀 | 被迫——每天被通勤拉扯两趟 |

**两个人都是被自己的处境画地为牢，只是牢的形状不一样。**

# 七、暗面层

## 1. 学区带的日常灰色

补习班、代刷、打印店里的各种"证明"、文具店卖烟给未成年、不查身份证的黑网吧、放学高峰的电动车流。

**每一笔单独看都不算犯罪，每一笔都需要一个"默认不看"的默契。** 这条巷子的秩序不靠警察，靠所有人都不多问。

## 2. 老公房带的常态

租金、拆迁传闻、独居老人、租住的学生与打工人、楼道里的杂物和谁也不认识谁的门。

## 3. 重点中学的另一面

排名、成绩榜、家长的期待、班主任的权力。**在一所市重点里，"掉队"是肉眼可见的。**

## 4. 新城那边的暗面是另一种

不是危险，是**空**。晚上十点半的棋盘新城，路上没什么人，只有一栋栋亮着屏幕的窗户。**她每天回来的时候，那盏灯多半是黑的。**

# 八、圈内层：她不知道的那一层

| 项 | 状态 |
|---|---|
| 她对圈内 | **完全不知道存在**。没人告诉过她，她也没见过任何异常 |
| 圈内对她 | **完全不知道她存在**。五年，零次感应记录 |
| 这片地方有异能者吗 | 按密度（十万分之一）算，这条线上**几乎没有**。老城学区带是学生、店员、老师、工人——最普通的那一层人 |
| 她为什么五年没被发现 | **不是藏得好，是从未出手。** 感应只有在她动用能力时才会触发（见第五节） |
| 唯一的裂缝 | 如果她在学后街动手——那里的"缝"能挡住摄像头，挡不住感应。**但前提是附近恰好有同类，而按密度算，这个概率极低** |
| 谁可能先找到她 | 不是管理局（这里不是重点区），不是家族（她没有血统标记）——**只可能是偶然撞上** |

> **她这个角色最大的资产是"信息差"**：她揣着一个自己不认识的东西揣了五年。
> 而这片生活圈的设计目标，就是**让这个信息差尽量晚一点结束**——她待的地方越普通，她越安全。

# 九、与别处的接口

1. **云渚理工大学**——她的旧梦，就在 `设定/云渚大学城.md` 里，也就是藤原花奈的主场。
   · 现在它只是志愿表上的一行字、公告栏上一张介绍。**这扇门现在还只是一张纸。**
   · 与花奈的空间隔离线（她在潮川／澜浦，花奈在云渚）**在城建上已经成立**：两条线前期不该碰面。
2. **后巷六号院**（藤原家老宅）同在澜浦，但在**南片**，与学后街（北片）不同片——保持隔离。
3. **「二楼」那间网吧**：不查身份证的地方，也是消息最杂的地方。她不去打听，但**坐在那儿就会听见**。
4. **她护过的人**：人设里写了"被她护过的人欠她人情"，这些人的落脚点可以后续挂在学后街与南江一中周边。
