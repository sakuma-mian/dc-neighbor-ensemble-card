# 城市模板（核心城市）

> **谁填这个**：驾驶员（你）。Agent 只做机制接口与一致性检查。
> **怎么用**：复制本文件改名填写。留空的项后面补。
> **为什么需要它**：城市的空间结构直接决定"玩家能去哪儿"，而"能去哪儿"是"高自由度"最基础的兑现方式——自由度如果没有具体的地点承载，会退化成纯靠模型即兴编地名。

## 一致性检查清单

- [ ] **C-01**：城市整体上不知道异能存在；异常只停留在都市传说层面
- [ ] **C-02**：城里存在管事的一方，且与三足鼎立结构吻合
- [ ] **C-03**：几百人这个量级能藏在这座城市里说得通
- [ ] **C-11**：没有设置"用异能会被摄像头拍到"这类物理痕迹机制
- [ ] **D-022**：管理局的据点形态符合"半官方"（明面有正当外壳）
- [ ] **D-025**：三个大族 + 一个没落旧家都有落脚处，且没落的那家处境能被看出来
- [ ] **D-026**：黑话在这座城市里有实际使用场景
