> **状态**：✅ **已定稿**——2026-09-16（第 06 阶 · 核心城市建设）

|---|---|---|
| **城市名** | **南江市** | 因主江「南江」穿城得名。全架空口径：城市名与全部地标名均为自造，不使用任何真实地名 |
| 现实原型参考 | 江口三角洲上的超级都会，两千余万人口 | 全架空之后，这一栏不再是"像哪座城"，而是给模型的**尺度锚**：楼多高、地铁多挤、房租多离谱、跨区通勤要多久 |

### 主江与两岸（附加地理）

| 项 | 内容 |
|---|---|
| 主江 | **南江**——自南向北穿城而过，在城北一侧汇入大江出海。本地人口语仍称「主江」 |
| 两岸 | 主江以西是历史老城与里弄（澜浦），主江以东是金融新城与空港（潮川）。本地人说「西岸／东岸」 |
| 支流 | **汇水**——穿过旧工业带与新建写字楼，本地人日常叫「内河」 |
| 两面临水 | 北面是江口（北江口国际邮轮港所在），南面是汐湾（外屿港与汐港海滩所在） |

## 二、社会切面

| 字段 | 南江市 | 说明 |
|---|---|---|
| **主导产业** | 四根柱子：**金融与航运**、**先进制造**、**科创与教育**、**枢纽与文旅** | 一句话：钱从江上来，货从海上去。制造落在沧湾与汐港，科创落在潮川与云渚 |
| **阶层分布** | 三档住区并存，加一层"漂浮者" | 老城原住民（澜浦里弄与老公寓）／跨城通勤的中产（汇津与潮川的精致社区）／园区与港区的外来劳动力（沧湾工人新村、汐港宿舍、远郊新城）；再加一层"住在这里但不属于这里"的人（西侨社区、租住白领、被项目拖住的研究员） |
| **治安状况** | **分层秩序**——核心区极严，边缘区放任 | 澜浦秩序最昂贵（监控最密、巡逻最频）；汐港港区与沧湾旧厂区明显放任。**报警有没有用，取决于你在哪个区。** 同一座城两套规则 |
| **网络与监控覆盖度** | 中高；**盲区集中在工业化外围** | 核心区几乎无死角。明确盲区：沧湾停产厂房与铁路支线、汐港封闭码头与沿海防护林、云渚废弃试验田与湖心岛。注意 C-11：异能不留物理痕迹，所以监控追的是"人"不是"能力"——它真正记录的是**谁和谁在一起**（而"谁和谁在一起"恰恰是澜浦最值钱的东西） |

## 三、异能者在城市里的分布

| 字段 | 南江市 | 说明 |
|---|---|---|
| **管理局的据点** | 明面：澜浦区 · **旧海关大楼**，挂「南江市公共安全应急处置中心」；不对外那层：潮川区 · **潮川数据园十七号楼** | 明面壳是政府序列里的正规单位，市民能查到、能投诉、能上门办事。选海关大楼，是因为它历史上本来就管"进出这座城的人与货" |
| **管理局据点的氛围** | **低调** | 外壳公开、程序正当；真正干活的那一层不对外，走上三层楼梯才会发现里面和牌子上的不一样。若改成"几乎不藏"，普通人就会看到不该看的东西，直接撞 C-01 |
| **家族的地盘** | 三大族按资源类型分：**澜浦＝门第与消息** ／ **沧湾＝重工业与工人网络** ／ **汐港＝货与通道** | 呼应 D-025 三强一弱。不按血统高低排座次，按"手上有什么"分 |
| **没落旧家的缩处** | **藤原家**（三强一弱里那一弱）· 澜浦 · **后巷六号院** | 面子还在，钱没了。守着几十年的旧账、旧人脉、旧秘密，守着整片等待收购的街坊——城里最好用的信息源，也是最容易被人吃干抹净的一家。**六号院已于开局前两周挂牌待售**（见第五节）。藤原家唯一在圈内立住的人（藤原花奈）已经与家族切割，人在云渚大学城；见 `设定/藤原花奈.txt` 与 `设定/云渚大学城.md` |
| **散人网的藏身处** | 藏身：云渚 · **湖心岛与无主宅院群**；中转：汇津 · **旧客运站旅馆区** | 靠什么活：情报、跑腿、替两边递话。最怕的不是被追，是被任何一方收编 |
| **普通人察觉到异常的程度** | **零星都市传说** | 不能再高（C-01：不能变成公开秘密），也不必更低（否则 D-026 的黑话体系与"隐于市"就没张力了） |
| **圈内黑话的使用场景** | ① 澜浦老城的**咖啡馆**——谈条件 ② 汐港的**仓门口**——不问货从哪来 ③ 汇津的**展会与酒店大堂**——人来人往，说什么都合理 | 呼应 D-026。**掩饰手法**：代号听上去就是外号或网名；黑话借用行业词（港区说「货」、厂区说「班次」、老城说「行情」），落在旁人耳朵里完全平常；谈强弱只说「别去惹」这类体感话，不报数字（D-049） |

| 项 | 内容 |

## 四、关键地点（十处）

| 地点名 | 谁的地盘 | 在那儿能发生什么 | 玩家的用途 |
|---|---|---|---|
| **旧海关大楼**（澜浦） | 管理局（明面） | **登记**、报到、被"谈话"、拿情报换掩护 | 合法身份的唯一入口，也是最早被盯上的地方 |
| **潮川数据园 · 十七号楼**（潮川） | 管理局（不对外那层） | 把异常改写成系统故障、事故报告或项目调整 | 想跟执法者做交易，得来这里 |
| **江畔步道与中央步行街**（澜浦） | 无主地段（**平民地标**） | 全市客流密度最高的商业轴线——最挤的地方最隐身 | 甩跟踪、约在人多处见面、靠观察一个人买东西的方式判断他缺什么 |
| **旧织造厂**（沧湾） | 重工那家／半遗弃 | **出过事的地方**，旧账的物理现场 | 挖旧事，然后碰到不该碰的人 |
| **十六号保税仓**（汐港） | 货运那家／管仓的人两边都收钱 | **黑市与情报交易的合体**：手续不齐的货、不写进单据的东西、临时通关 | 拿到不能明说的东西，或把东西送出去 |
| **旧客运站旅馆区**（汇津） | 散人网 | 接头、临时避风、跨城交易、身份转换 | 第一次被圈内人正式找上门，多半在这里；换个名字住三天也在这里 |
| **云渚湖心岛与无主宅院群**（云渚） | 散人网藏身处 | 藏人、疗伤、让一件说不清的事被包装成意外或自然灾害 | 躲与养伤；也是把秘密埋掉的地方 |
| **后巷六号院**（澜浦） | 没落旧家 | 空置老楼、等待收购的整片街坊、不愿离开的原住民 | 用信息换东西——他们缺钱，不缺旧事 |
| **深坑植物园 · 老坑**（云渚） | 三方默契的中立区（**安全屋**） | 唯一能压住感应的场所——用能力不被远距离读到 | 做那些"绝不能被发现"的事；代价是要还一次人情 |
| **零号房**（云渚 · 大学城学生街书市） | **藤原花奈**（圈内代号「第零天使」）／不属于任何一方 | 掮客据点：牵线、介绍人、担保。也是她收藏"素材"与藏本体的地方 | 想找人、想搭线、想让人替你担保——来这儿。**前提是她愿意接** |

**覆盖检查**（模板要求的五类）：官方入口 ✅（旧海关大楼）｜情报交易点 / 黑市 ✅（十六号保税仓，货与人脉分别是两处：**零号房**是人与信誉的那一处）｜平民普通人地标 ✅（江畔步道与中央步行街）｜出过事的地方 ✅（旧织造厂）｜安全屋 ✅（深坑老坑）。

## 四之二、片区：云渚大学城

> 云渚区内部的一个片区，**藤原花奈主线剧情的发生地**。完整设定见 `设定/云渚大学城.md`。

| 项 | 内容 |
|---|---|
| 位置 | 云渚区北部，绕云渚湖展开。西是西屏山，东南是泾口镇。**到澜浦一小时车程** |
| 规模 | 师生合计十几万，几所高校沿湖分布，连成独立于市区的生活圈 |
| 六块片区 | 湖东西屏大学老校区 ／ 湖西理工与研究所组团 ／ 湖北医学校区 ／ 学生街与书市 ／ 绿道环线 ／ 云渚湖与湖心岛 |
| 圈内地位 | **管理局覆盖最薄的一片**——没有家族地盘、没有黑市、离中心一小时。不是无人看管，是没人重点看管 |
| 暗面 | **全城最干净的擦痕现场**：每年几万人进出，一个人消失有太多合法出口（退学、转学、休学、出国、延毕），**不会有第二次追问** |
| 校园痕迹 | 西屏大学有**藤原楼**（家族当年捐建的文学院老楼，现为文献与档案学系教学楼）与**藤原奖学金**（家族垮后靠基金利息撑着，每年还在发，而没有藤原家的人来领过） |

## 四之三、片区：顾清寒生活圈（跨区一条线）

> 核心群像第 02 号**顾清寒**的落脚点。形状与云渚大学城相反——**它不是一片地方，是一条线**。完整设定见 `设定/顾清寒生活圈.md`。

| 项 | 内容 |
|---|---|
| 形状 | 每天来回两趟的一条跨江通勤线，**四小时在路上**。她的生活不是被分成三块，是被剪成两半 |
| **潮川侧 · 棋盘新城**（家） | 潮川区西侧靠江的住宅组团，2015 年前后新城开发的产物。**按棋盘格规划**：横平竖直的街道、按格编号的组团——规划得最理性，住起来最记不住（三区 7 栋、三区 7 号院、C-7 街区三套编号并行）。她家的房子是**一间"没人生活过的空房子"**：家具成套、没被用旧过、阳台常年没晾衣服。**她真正的生活痕迹全在老城那条巷子里** |
| **澜浦侧 · 南江一中**（学校） | 市重点高中，位于澜浦区**北片**的老公房带（不是西堤、长街那些商业核心）。**她是靠自己考进去的**——这是"沉默之前的她"留下的最后一个证据 |
| **澜浦侧 · 学后街**（她真正的地盘） | 南江一中、实验学校、一所职校与两三所初中共同的后街。老、挤、有烟火，人也杂——**没人会多看她一眼**。她的地盘是**她初中那所学校旁边**，不是现在就读的学校旁边（即"地盘没换"的物理版本）。两个固定点：**巷尾小卖部**（赊账本上有她的名字，那是她生活里唯一长期记得她的成年人）、**「二楼」**（老楼二层的黑网吧，不查身份证，她有固定机位） |
| 过江线 | **轨交 4 号线**（本地人叫"过江线"）＋**澜川大桥**（名字由澜浦＋潮川合成）。单程约一小时；高三作息下 05:30 出门、22:30 到家；**末班地铁是她真正的门禁** |
| **机制口径（防硬伤）** | 新城监控全覆盖且互联，老城监控补丁式且互不联通——**所以新城更无处可藏，老城到处是缝**。但这句只对摄像头和人眼成立：**那些"缝"挡不住同类感应**。她出手时，附近有同类就会被读到，不管巷子多隐蔽。（这正是她五年没被发现的原因——不是藏得好，是从未出手） |
| 空间隔离 | 与云渚大学城（花奈的主场）在城建上已隔开，两条线前期不该碰面。藤原家老宅**后巷六号院在澜浦南片**，学后街在**北片**，物理上不同片 |

## 五、时间与开场

| 字段 | 南江市 | 说明 |
|---|---|---|
| **开局时间点** | **六月下旬，梅雨尾期，一个周四的傍晚，雨刚停** | 全城潮湿、闷热，地铁挤满下班的人；台风季还没正式开始，但气象台已经在盯汐湾以南的一个热带气旋。落进 `/世界/日期` |
| **最近的"大事"** | **澜浦后巷的六号院，两周前挂牌待售了** | 不是新闻，是一根针：没落旧家撑不住，开始变卖家底。圈内人都知道那栋老屋子里留着什么——旧纸、旧账、旧人脉的凭据。挂牌两周还没人摘牌，因为谁都在等别人先动。落进 `/世界/事件线`（只记结果） |
| **开局时局状态** | **明面平静、圈内紧绷** | 对普通人来说，这只是一座正在入梅的超级城市，照常上班、照常挤地铁；对圈内人来说，有人正在公开变卖家底，三方都在算同一件事：那批旧纸该由谁拿到手 |

**为什么这么定**：一件"刚发生过的事"让世界显得刚动过，一根"还在走的时钟"保证它还会继续动。六号院的挂牌同时扮演了这两个角色，所以不必再加第二场事故。

- [x] **C-01**：城市整体上不知道异能存在；异常只停留在都市传说层面 → 普通人察觉程度定为"零星都市传说"；管理局外壳是普通政府单位，不公开异能
- [x] **C-02**：城里存在管事的一方，且与三足鼎立结构吻合 → 管理局（半官方，D-022）／三大族＋一个没落旧家（D-025）／散人网，各有明确落点
