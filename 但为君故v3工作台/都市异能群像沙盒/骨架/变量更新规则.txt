# 变量更新规则

## 你要做什么

在正文结束后，输出一个 <UpdateVariable> 块，记录本轮剧情中**真正发生的变化**。

块的结构固定如下：

<UpdateVariable>
<analysis>
逐行说明本轮发生了什么变化，每行都要对应下面 JSONPatch 里的至少一个操作。
没有任何变化时，写"本轮无状态变化"。
</analysis>
<JSONPatch>
[
  {"op":"replace","path":"/世界/日期","value":"5月14日"},
  {"op":"replace","path":"/玩家/暴露程度","value":35}
]
</JSONPatch>
</UpdateVariable>

## 四条铁律

1. **只用四种操作**：add、replace、remove、move。
   不要使用 delta、insert 或任何其它操作。

2. **replace 只能改已经存在的路径。**
   如果某个角色或字段还不存在，必须先用 add 写入**完整对象**，之后才能 replace 它的子字段。

   例：第一次遇到某角色时——
   {"op":"add","path":"/角色/张三","value":{"故事线进度":"","位阶传闻":"中游","位阶真实":"高位","玩家已知程度":"未知","与玩家的账":[],"被掌握的底牌":[],"圈内代号":"","已接触":true}}
   （位阶两栏必须填五个档位之一：不入流 / 中游 / 高位 / 传闻极强 / 深不可测。
     传闻值可以低于真实值——那表示他在藏级；也可以高于真实值——那表示他虚张声势。）

3. **analysis 里提到的每一项变化，都必须在 JSONPatch 里有对应操作。**
   不许分析了却不改，也不许改了却不分析。

4. **没有变化的字段不要写。** 只输出本轮真正变了的字段，不要把整套变量重写一遍。

## 字段含义与取值范围

### 玩家

- /玩家/能力本质 —— 觉醒后固定的那个能力。文字。**一经确定不再改写。**
- /玩家/掌控度 —— 对同一能力用得有多精细。数值 0–10。一点点 = 50 战力。
- /玩家/承载上限 —— 能连续用多少、能压多大。数值 0–10。一点点 = 50 战力。
- /玩家/基础战力 —— 战力系统的核心数值。数值 0–1300。**它是投影**：
  = 掌控度×50 + 承载上限×50 + 异化修正 + 血统加成。
  **平时绝不修改**，只在下面「跃迁」发生时同步更新。
- /玩家/内在损耗 —— 身体与精神被掏空的程度。数值 0–100。用能力上升，休息下降。
- /玩家/暴露程度 —— 出手被同类感应到的风险积累。数值 0–100。用能力上升，时间过去或休整后回落。
  **无同类在场、无人处的出手不涨**（这是玩家可以主动利用的一条）；**在钝化地点内出手也不涨**（见第五节）。
- /玩家/身份记录 —— 玩家在官方档案里的身份。只能是：未登记 / 被登记 / 被通缉。**不会自己回落。**
- /玩家/异化状态 —— 是否走那条危险路线。只能是：未涉足 / 进行中 / 已异化。
- /玩家/血统认知 —— 玩家对自己出身的了解。只能是：未知 / 存疑 / 已知。
- /玩家/当前状态 —— 会过期的临时状态，键值对。例：{"身上有伤":"左臂"}。过期就 remove。
- /玩家/圈内代号 —— 别人给玩家起的名字。文字。**必须是别人给的**，玩家不能给自己起。

**暴露程度与身份记录的区别（重要）**：
- 暴露程度上升 = 你越来越藏不住；
- 身份记录变化 = 你在档案里变成了另一种人。
- 这两件事不同：你可能被通缉但暂时没人找到你，也可能身份干净但刚出手闪了一下。

### 角色（每个核心角色一条记录，key 用真名）

- /角色/{真名}/故事线进度 —— 他走到哪一步了。文字，写明当前处在哪个阶段。
- /角色/{真名}/位阶传闻 —— 圈内以为他是什么水平。只能是：不入流 / 中游 / 高位 / 传闻极强 / 深不可测。
- /角色/{真名}/位阶真实 —— 他实际是什么水平。取值同上。
- /角色/{真名}/玩家已知程度 —— 玩家对他真实水平的掌握程度。只能是：未知 / 有传闻 / 已确认。
- /角色/{真名}/与玩家的账 —— 两人之间的人情与过节。字符串数组。例：["欠他一次人情","他失信于我"]。**用标签，不要用好感度数。**
- /角色/{真名}/被掌握的底牌 —— 玩家已经掌握了他哪些底牌。字符串数组。
- /角色/{真名}/圈内代号 —— 他的圈内代号。文字。
- /角色/{真名}/已接触 —— 是否已经和玩家打过交道。true / false。

**位阶的三个字段必须分别判断，不能混用**：
- 位阶传闻是"别人怎么说"，可以不准、可以被故意传歪；
- 位阶真实是"他到底多强"，通常不变；
- 玩家已知程度是"玩家知道多少"，只有当玩家真的验证过、或拿到可靠情报时才提升。
- **玩家已知程度没提升时，即使位阶真实很高，叙事里也不能让玩家"看出来"。**

### 世界

- /世界/日期 —— 游戏内日期。文字。玩家主动跳过时间时推进。
- /世界/事件线 —— 已发生的关键事件。字符串数组。**只记结果，不记过程。**
- /世界/势力状态 —— 各方势力当前状况。四个字段：管理局 / 家族 / 散人网 / 没落旧家。各一句话。
- /世界/当前引力源 —— 现在有谁在找玩家。字符串数组。例：["管理局在查觉醒记录","散人网想接触玩家"]。
- /世界/结局进度 —— 整体推进到哪个阶段。文字。

**事件线的写法要求**：
- 记"结果"不记"过程"——写"某据点被清掉了"，不写"某某和某某在某地打了一架又跑了"；
- 一条不超过一句话；
- 不要记录玩家已经知道、但世界层面并无变化的事情。

## 什么时候该更新什么

- 玩家用了能力 → **有可能被同类感应到时**暴露程度上升；内在损耗上升；若被看见，可能改身份记录。
  （在无人处、无同类在场的出手，暴露程度**不涨**；在钝化地点内出手也**不涨**，见第五节。）
- 玩家休息、过了一段时间 → 内在损耗下降；暴露程度下降；日期可能推进。
- 玩家发生**跃迁** → 掌控度或承载上限上升，并同步重算基础战力（见下一节）。
- 和某个角色产生人情或过节 → 该角色的"与玩家的账"。
- 玩家验证了某人的真实水平 → 该角色"玩家已知程度"提升；"被掌握的底牌"追加。
- 某角色的剧情线往前走了 → 该角色"故事线进度"。
- 世界层面出了事 → 事件线追加；相关势力状态改写。
- 有人开始找玩家 → 当前引力源追加。
- 玩家第一次遇见某角色 → 用 add 写入该角色的完整记录，已接触设为 true。

## 战力系统（重要，逐条遵守）

### 一、基础战力只在跃迁时变

**平时每一轮都不许修改 `/玩家/基础战力`。** 它只在这一类事件发生时更新，叫"跃迁"：

| 跃迁类型 | 触发条件 | 增幅 |
|---|---|---|
| **磨** | 有安全场地 + 大段时间 | +50 |
| **逼** | 生死边缘、强敌压迫、被逼到绝境 | +90 |
| **悟** | 想通了自身能力的本质（剧情事件） | +150 |

三条限制，必须同时遵守：

1. **单次封顶**：500 分以前单次最多 +200；500–700 之间最多 +90；700 以上最多 +50。
   （这个封顶会**自动截断**上面的类型增幅——比如 700 分以上的"悟"也只加 +50。）
2. **间隔**：两次跃迁之间至少要有一次完整休整；
3. **成长闸门**：掌控度或承载上限只要**已经到 4**，就不能再靠"磨"提升——必须"逼"；
   只要**已经到 8**，就不能靠"逼"——必须"悟"。
   （大白话：能自己偷偷练上去的只有 200 分，再往上必须把命押出去。）

跃迁发生时，同时做三件事：
- 改 `/玩家/掌控度` 或 `/玩家/承载上限`（按突破方向选一个）；
- **重算并写入 `/玩家/基础战力`**；
- 把代价写进 `/玩家/当前状态` 或 `/世界/事件线`。

### 二、基础战力必须与两条成长轴一致

每轮更新完变量后自检一次：

```
基础战力 应当等于  掌控度×50 + 承载上限×50 + 异化修正 + 血统加成
异化修正：未涉足 0 ／ 进行中 100 ／ 已异化 200
血统加成：首版一律 0
```

对不上时，**以掌控度与承载上限为准**，改写基础战力。

### 三、战力档位（圈内黑话，用于叙事，不写进变量）

| 基础战力 | 圈内说法 |
|---|---|
| 0–199 | 不入流 |
| 200–399 | 中游 |
| 400–599 | 高位 |
| 600–799 | 传闻极强 |
| 800–1300 | 深不可测（**一律不表态，只说"别去惹"，不说任何数字**） |

### 四、战斗当轮怎么判

**当轮战力**（**只在心里算，绝不写进变量**）：

```
当轮战力 = 基础战力
         + 异能修正（增幅每回合+30，上限+150；爆发单回合+150~250后回落200；
                     干涉减对方100~200；信息型不加分，改"情报"）
         + 武器加成（媒介 +100 ／ 纯物理 +50 ／ 混合 +150，**三选一，不许叠加**）
         + 环境修正（狭窄−100 ／ 夜间+50 ／ 人多−100 ／ 无人处无修正但暴露不涨）
         + 战斗表现（先手/奇招/识破 各+50 ／ 冒险+100 ／ 被拖节奏−100）
         + 状态修正（损耗40–69 → −100 ／ 70–89 → −250 ／ 带伤 −100~−300 ／
                     充分准备 +100 ／ 被偷袭 −150）
         − 缴械惩罚（纯物理武器 −150 ／ 媒介或混合 −100）
```

**判定**：

| 双方当轮战力差 | 结果 |
|---|---|
| > 200 | **碾压**。弱者只能逃，只能被拿捏 |
| 50–200 | **单方面占优**。强者定走向，弱者能脱身并付代价伤到对方 |
| < 50 | **同档缠斗**。看相性／情报／准备／代价意愿／第三方 |

**四条闸门，违反了战斗就不成立**：

1. 只有基础战力差 200 以内，状态与情境才能翻转胜负；
2. 所有临场修正加起来不超过基础战力的 50%；
3. 武器只算一处；
4. 环境与"准备"只吃一个（场地当场选的按环境算，提前布好的按准备算）。

**弱者要赢，必须满足三者之一**：提前布了局 ／ 付出了不可逆的代价 ／ 第三方在场改变了局面。
三者都不满足，**不许出现以弱胜强**。

### 五、感应读数（写进叙事时的口径）

- 对方基础战力比你高 200 以上 → **完全感应不到**；
- 高 50–200 → 只有压迫感，判不出档位；
- 差距 50 以内 → "跟我差不多"，分不出高下；
- 你高 50–200 → "他比我弱一档"；高 200–400 → "弱两档，能摸到底"；高 400 以上 → "一眼看穿"。

**感应只读得出"量"，读不出"质"**：你能感觉到他是个硬手，但**不知道他是什么能力**。

**钝化地点（全城只有三处，写叙事时必须遵守）**：

- **云渚 · 深坑植物园的老坑**——唯一能真正压住的地方。坑底岩层够厚，感应读数**压低一大档**：
  原本"对方比你高 200–400、能摸到底"的距离，在坑底只剩"模糊压迫感"；原本"高 200 以上完全感应不到"
  的就更读不到。
- **沧湾旧防空设施最深处**、**汐港十六号仓底**——只压**半档**，且不稳定（时灵时不灵，由叙事决定）。
- **关键限制**：它保护"用能力"，**不保护"离开"**。在坑底出手，暴露程度不涨；一旦离开坑口，
  感应照常成立。**任何人都不许把老坑当成长期避难所**。
- **归属与代价**：名义上挂在云渚植物园的科研保育序列，实际靠管理局／家族／散人网三方不成文的默契——
  **谁先在坑底动手，另外两家立刻联合**。看着它的人不收钱，收人情。
- **它算"当轮修正"，不写进变量**（同"当轮战力"）。这一条**不新增任何字段**。

### 六、秩序铁律

- 武器不放大异能，**只集中异能**；没有异能根基的人拿特殊材料武器**没有任何加成**；
- 相性只能决定同档内的胜负细节，**绝不能用来跨越 200 分的差距**；
- **越级获胜必须付出不可逆的代价**，并写进事件线。

## 不要做的事

- 不要重写没有变化的字段；
- 不要把整套变量重新输出一遍；
- 不要在变量里写剧情描写或对话；
- 不要自己发明新的位阶等级或枚举值；
- **不要在非跃迁场合修改 `/玩家/基础战力`**；
- **不要把"当轮战力"（含环境／表现／武器修正）写进变量**——它每场都变，写进去就会污染存档；
- **不要在叙事正文里说出任何战力数值或档位数字**，只用圈内黑话和体感；
- 不要写 /世界/变量结构版本 —— 这个字段由脚本管理。
