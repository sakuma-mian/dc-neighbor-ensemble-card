# 开局匹配规则

> **这份文件是机制规则，不是内容。** 它规定"开局时玩家最可能接触到谁"怎么算出来。
> 对应决定：D-036（开局接口 = 匹配算法）。
> 剧情与角色人设由驾驶员提供，本规则只负责把两者接起来。
> 建立日期：2026-08-18（第 4 阶）

---

## 一、这个规则解决什么

驾驶员的设计原话：

> 按照主控给出的人设，结合世界书中角色的人设，来决定主控最有可能在落地时与谁接触（包含角色的性格，落地地点，职业，过往等因素）

所以要解决的是：**把两份人设放一起，算出最合理的第一次相遇。**

## 二、为什么值得单独做（而不是写一段固定开场白）

| 固定开场白 | 匹配算法 |
|---|---|
| 无论玩家选什么人设，开局都是同一段，只换个称呼 | 玩家选"刚毕业的大学生"和"退役老刑警"，开局会真的不一样 |
| 新增角色要回来改开场白 | 加新角色，开局**自动**多出新可能性 |
| 开局是写死的 | 开局是算出来的 |

**这也是角色创建页存在的意义**——它收集的信息直接决定开局走向。

---

## 三、输入项

### 输入 A：主控人设（来自角色创建页）

| 字段 | 必填 | 说明 |
|---|---|---|
| 职业 / 身份 | ✅ | 最影响"会在哪、会遇到谁" |
| 年龄段 | ✅ | 影响会被谁当同类对待 |
| 通常活动的场所 | ✅ | 与角色的"常驻地点"直接匹配 |
| 性格倾向 | ○ | 影响匹配的角色类型（互补或同类） |
| 过往经历 | ○ | 用来和角色的"过往"产生因果关联 |
| 血统认知 | ✅ | 决定开局时他自己知道多少（变量 `/玩家/血统认知`） |
| 觉醒情境 | ✅ | 他在哪、怎么觉醒的——**决定开局那一刻的位置** |

### 输入 B：每个核心角色的人设（来自角色人设文件）

| 字段 | 必填 | 说明 |
|---|---|---|
| 常驻地点 | ✅ | 与玩家活动场所匹配 |
| 职业 / 日常身份 | ✅ | 与玩家职业匹配 |
| 性格 | ○ | 与玩家性格匹配 |
| 过往 | ○ | 与玩家过往产生关联 |
| 是否已接触玩家 | ✅ | 已接触的不参与开局匹配（变量 `/角色/{名}/已接触`） |

**注意**：`常驻地点` 这一项同时依赖城市设定。**这就是为什么人设和城市必须一起准备**——缺了城市，这里算不出来。

---

## 四、匹配规则

### 规则 1：先筛除

移除所有 `已接触 = true` 的角色。

### 规则 2：逐项打分

| 匹配项 | 命中时加分 | 判定依据 |
|---|---|---|
| **地点重合** | +3 | 玩家的"通常活动场所"与角色的"常驻地点"重合或相邻 |
| **职业接触** | +3 | 玩家的职业会自然接触到该角色的日常身份（客户 / 同事 / 邻居 / 管辖关系 / 生意往来） |
| **因果关联** | +2 | 玩家的"过往经历"与角色的"过往"能构成因果关系（旧识 / 受过其恩 / 有过节 / 同一件事的当事人） |
| **性格相性** | +1 | 性格倾向于"会主动接近陌生人"（外向、好奇、控制欲强、有求于人） |
| **势力吸引** | +2 | 玩家的身份或觉醒情境会**天然引来某一势力的注意**（例如：觉醒时动静大 → 引来管理局或家族） |

### 规则 3：取最高分

**最高分者成为第一个接触者。**

### 规则 4：同分处理

同分时按以下顺序决定，**第一个满足的生效**：

1. 势力分布更均衡的那个（避免连续开局全落在同一势力）；
2. 性格更主动的那个；
3. 由驾驶员预先指定的优先者。

**为什么要有这条**：没有兜底规则时，模型会随机选一个——那样"匹配算法"就退化成抽签了。

### 规则 5：必须给出理由

选出结果后，**必须能一句话说清为什么是他**。

例：*"你是个值夜班的急诊护士——他上周被送进来过。"*

**这条是硬要求**：说不清理由的开局，玩家会觉得是随机安排，沙盒感立刻打折。

---

## 五、输出的东西

匹配完成后，产出**一条真实的玩家开局发言**（不是系统提示，是玩家自己说的话）。

结构：

```
[玩家的人设简介，一两句]

[开局情境：他在哪、正在做什么]

[玩家开口说的第一句话 / 做的第一个动作]
```

**为什么是"玩家自己发言"**：规范明确要求开局页的最终动作**等同于玩家在输入框发了一条正常消息**，并走正常发送链。不能凭空生成一条消息冒充玩家，也不能跳过正常流程。

---

## 六、变量落点

匹配结果通过正常回复链落到这些字段（**不在创建页里直接写**，规范明确禁止：预览阶段不得写正式变量）：

| 字段 | 何时写 |
|---|---|
| `/玩家/能力本质` | 玩家第一次真正使用能力、或剧情明确揭示时 |
| `/玩家/血统认知` | 由创建页的选择决定初始值 |
| `/玩家/圈内代号` | 留空——**代号必须由别人给** |
| `/玩家/暴露程度` | 若开局觉醒情境动静大，初始值 > 0 |
| `/玩家/身份记录` | 默认 `未登记`；若开局就被注意到，按剧情推进 |
| `/角色/{第一个接触者}/已接触` | 用 add 写入该角色完整记录时设为 true |
| `/世界/日期` | 由城市设定里的开局时间点决定 |
| `/世界/当前引力源` | 第一位接触者的引力理由 |
| `/世界/事件线` | 若开局涉及已发生的大事，记一条（只记结果） |

## 八、待验证

- [ ] **规则 2 的权重是否需要调整**——需要真实跑几局才能判断"最高分者"是否合理
- [ ] **同分情况是否常见**——如果经常同分，说明权重要重调
- [ ] **规则 5（能说清理由）是否总能满足**——算出来的人如果说不清理由，说明匹配项设计有问题
