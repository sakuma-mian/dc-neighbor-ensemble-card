> **这份文件是什么**：驾驶员动笔写五条故事线时的**参考清单**。写的时候不必背，遇到卡壳就来对一眼。

## 〇、三句话先记住

1. **格式是我的活，不是你的活。** 你用大白话讲，我翻成机制看得懂的八格。卡壳时写"你给建议"或"跳过"。
2. **你写的是"人会怎么动"，机制负责让世界记住它。** 所以真正要你盯的只有一件事：**每一步之后，世界有什么不一样了。**
3. **每条线都要能当"玩家的第一扇门"**——因为开局是**算**出来的，任何一条都可能被算中。

## 一、你的边界与我的边界

| 谁 | 负责什么 | 状态 |
|---|---|---|
| **你（驾驶员）** | 核心角色人设、城市建设、**剧情线**、**结局安排** | 人设 5/7 已定档；城市已冻结；**剧情线＝现在这一步** |
| **我（Agent）** | 机制引擎、MVU 变量表、故事线**容器与格式**、开局匹配逻辑、一致性检验、落地到角色卡 | 骨架已完成；地基三件已落地 |

**这条边界的实际含义**：
- 我**不发明剧情**、不替角色写背景、不替城市起名字；
- 但我要保证：你写的东西**装得进卡的机制**、**不跟已冻结的 63 条决定打架**、**在真实 SillyTavern 里跑得起来**。

**所以你会看到的两种回应**：
- 「这一条装不进去，因为……」→ 我改容器或提方案；
- 「这一条跟第 N 阶的某条冲突」→ 你裁决改哪边。
- **我不会说「这样写不好」**——那是你的领域。

## 六、每一步都要满足的结构要求

| 字段 | 要求 | 不合格的后果 |
|---|---|---|
| **标记** | 写成 `第1步：<短句>`；同一角色不许重名 | 它就是 `/角色/{真名}/故事线进度` 的取值，模型靠它判断走到哪 |
| **他缺什么** | 写得清，且**玩家手上可能有他缺的东西** | 没有缺口，玩家只能旁观 |
| **玩家介入的走向** | **至少两种**（介入 / 不介入），且结果真的不同 | 两种走向一样，玩家的选择就是假的（破 `D-035`） |
| **涟漪出口** | 写明这一步**影响到谁、影响什么** | 没有它，五条线就是五个独立剧情（破 `D-033`） |
| **自主行动性** | 玩家完全不介入，这条线**自己能走到哪一步** | 答"原地不动"＝这个 NPC 是功能件，不是活人（破 `D-002` 真群像） |
| **涉及的变量字段** | 只能用骨架里已有的（见下） | 自造字段写不进去，会静默丢失 |
| **交汇** | 和对上号（见 `剧情/交汇表.md`），且**双向核验** | 单向写的交汇，在对方那条线里对不上 |
| **时序** | 与 `剧情/共同开局.md` 那一格对齐 | 两条线互相矛盾，玩家会察觉世界是假的 |

**可用变量字段（不能自造）**：
- 玩家：能力本质 / 掌控度 / 承载上限 / 基础战力 / 内在损耗 / 暴露程度 / 身份记录 / 异化状态 / 血统认知 / 当前状态 / 圈内代号
- 角色：`故事线进度` / 位阶传闻 / 位阶真实 / 玩家已知程度 / 与玩家的账 / 被掌握的底牌 / 圈内代号 / 已接触
- 世界：日期 / **事件线（上限 12 条，省着用）** / 势力状态 / 当前引力源 / 结局进度

> **不要写**「好感度」「NPC 当前位置」「他的心情」——骨架里**没有**，也不打算加。

## 七、战力与战斗：写作红线

> 完整在第 05 阶（D-048~D-062）。这是**最容易写崩的一阶**，因为写起来很爽。

| 红线 | 内容 |
|---|---|
| **数字只给玩家自己看** | NPC 一律用**圈内黑话与区间**。玩家读不出别人的确切实力 |
| **不掷骰** | 差 **200 分**以上＝碾压；差 **50–200**＝占优；差 **50 以内**＝缠斗 |
| **想跨 200 分赢，必须有事件解释** | 三个例外**只能选一个**：布了局 / 付了**不可逆**的代价 / 第三方介入（`D-062`） |
| **成长是跃迁制** | 平时不涨，只在关键事件跳，**每次自带代价**。单项 0→4 靠**磨**、4→8 靠**逼**、8→10 靠**悟** |
| **武器只算一处** | 物理武器（异能者也会流血）/ 特殊材料武器。缴械 −100 ~ −150 |
| **临场修正 ≤ 基础战力的 50%** | 防止"这一场我超常发挥"变成万能借口 |
| **感应只读得出"量"，读不出"质"** | 知道你打不过他，但**不知道他会干什么**（`C-09`） |
| **老城的"缝"只挡人眼，挡不住感应** | 只要出手，附近有同类就一定会被读到——巷子、摄像头都帮不了（第 06 阶 `D-078`） |
| **"写死的一条"** | 凡是你给了"越级"的能力（羽笙的倒流 / 沉秋的极限爆发 / 诺薇拉的大规模拆解），**代价必须真的不可逆**。写成"疼一下就好"，角色立刻变成免费越级的怪物 |

**五个人各自的战力位置（写冲突时的标尺）**：
花奈**高位**（400–599，信息型，实力全兑现在布局）／沉秋**中游**（200–399，增幅型，但极限爆发是断档的另一回事）／羽笙**中游**（挂账，依赖血统加成）／清寒**不入流**（0–199，但反伤"不设上限"）／诺薇拉**不入流**（0–199，但能力效果**远超**位阶）。

> **注意两处"位阶不反映威胁"**：清寒与诺薇拉。**弱不等于无害**——这正是这张卡的玩法。她们俩的越级都走 `D-062` 例外通道 (b)。

## 九、你刚说的「流沙之誓是核心冲突」——带来的三件事

> 驾驶员 2026-09-17 原话：**「楚羽笙身上带着这个剧情的核心冲突点（流沙之誓），五名角色的剧情都将围绕着这个冲突点来展开。」**

这句话把第一版的**主梁**定了。好消息是它本来就有底子——你早就在沉秋档案里写过：

> 「持有者 → 寻找者 → 中人。**这不是主线，是串珠——但它是一根真的线，玩家可以从任何一头切进去。**」

**但它同时带来四件必须处理的事——第一件是红线，先看这个：**

### 9.0 ⚠️ 红线：那块表与时间能力的因果界，**现在不能碰**

> `设定/楚羽笙.txt` 第 179–180 行原文：
> 「**必须划清的一条界**：这块表的作用与她「时间停止／倒流」能力之间的因果关系【待定】——**在表单独创作完成前，两者不得混写，否则未来必然冲突。**」

**也就是说**：那块表**还没有被写**——它是羽笙档案里登记在待补清单上的一项，身份是"**单独创作**项目"、**前期剧情的展开核心点**。
所以在它完成前：

| | 内容 |
|---|---|
| ✅ **可以写** | 有人在找它、谁听说过它、它在谁手上、它长什么样、谁想拿到它 |
| ❌ **不能写** | 它为什么能怎样、它跟"时间"有什么关系、她用它能做什么 |

**一句话**：**"有人在找它"可以先热，"它是什么"必须压着。**

> **完整的六条红线、既有事实与知情梯，都收在 `剧情/流沙之誓.md`。** 动笔前建议把那一份也翻一眼。

### 9.2 沙盒感需要保护

**风险**：如果五个人的第 1 步都直接冲着那块表去，那这张卡就变成**"所有人都在找怀表"**——串珠式会退化成一条全局主线，`D-035`「引力而非轨道」就废了。

**机制上的保护办法**（建议，由你定）：**每一条第 1 步都不依赖"流沙之誓"**。
让五个人**各自先因为自己的事开门**，那块表是**他们后来撞上的同一件事**，而不是**他们一开始就在找的同一个东西**。

## 十二、写完交给我的时候，请附三句话

这是 `骨架/故事线模板.md` 里本来就要问的，提前说：

1. **这条线你希望它优先服务什么**？（人物弧光 / 世界推进 / 给玩家提供选择）
2. **有没有必须保留的元素**？（不能改的部分）
3. **有没有你不确定的地方**？（希望我重点看的地方）

有这三句，我的检验会准很多；没有也能做，只是我会多问一轮。
