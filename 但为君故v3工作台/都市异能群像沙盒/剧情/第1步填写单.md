## 一、怎么用这份单子

1. 五块，一块一个角色。每块上半是**已填的起点状态**（出自你的档案，带出处），下半是**待你填的第 1 步**。
2. 你只需要填每块里那张「第 1 步」表的八格。**用大白话写就行，不用管格式**——Agent 负责落成正式文件。
3. 拿不准的地方直接写"不确定，你给建议"，或写"跳过"。**空着比写错好**。
4. 填完发给 Agent，Agent 按下一节和第五节做检验与落地。

## 二、第 1 步独有的硬约束（**先读这一节再动笔**）

第 1 步和后面的第 2、3 步不一样。它多担一重身份：

> ### 第 1 步必须是**每条线都能当"第一扇门"**的那一步。

原因是第 03 阶冻结的开局机制（D-036）：**开局是算出来的，不是写死的**。

```
玩家在角色创建页填的人设（职业 / 活动场所 / 过往 / 觉醒情境）
        ×
五个角色各自的（常驻地点 / 日常身份 / 性格 / 过往）
        ↓
算分 → 最高分者 = 玩家的第一个接触者
```

**这意味着：任何一条线都可能被算中，成为玩家的第一次相遇。**

| 由此产生的硬要求 | 说明 |
|---|---|
| **① 五条线的第 1 步都必须能接住一个"刚觉醒、未登记、血统不明"的陌生人** | 这是 `C-12` 定的玩家开局。不能有哪条线假设"玩家已经知道圈内的事" |
| **② 必须给出"为什么是他"** | 开局匹配规则第 5 条：**必须能一句话说清理由**。说不清理由的开局，玩家会觉得是随机安排，沙盒感立刻打折 |
| **③ 引力理由必须是剧情内理由** | 不能是"系统指派"。可用：他查到你的底 / 他被你的觉醒刺激了同类感应 / 他想用你 / 他被你身上某样东西吸引（`D-035`） |
| **④ 玩家拒绝后不能卡住** | 拒绝 → 引力转向别的**线**，不是原地等待 |

**一句话原则**（第 03 阶原文）：

> **沙盒感不是靠"没人管你"实现的，是靠"每个方向都有人真的在等你"实现的。**

## 三、格式要求（**照这个写，否则装不进机制**）

### 3.1 「标记」怎么写

```
第1步：<一句话，六个字到十五个字>
```

- 例（格式示范，非本项目内容）：`第1步：六号院挂牌`
- **这个标记会成为变量 `/角色/{真名}/故事线进度` 的取值**（`N6` 之外的核心字段，见 `骨架/变量结构约束.js`）。
- 模型每轮靠读它来判断"这条线现在走到哪"。
- 因此**同一角色的标记不能重名**，且**改写标记等于改剧情进度**——写定后别随便改字。

### 3.2 每步八格必须齐全

缺任何一格，线会在那个位置卡住或乱跳（`故事线容器格式.md` §一 列了五种翻车方式）。**「玩家介入的不同走向」至少两种（介入 / 不介入）。**

### 3.3 可用变量字段（**不能自造**）

对照 `骨架/变量结构约束.js`，你只能引用这些字段：

| 层 | 可用字段 |
|---|---|
| 玩家 | 能力本质 / 掌控度 / 承载上限 / 基础战力 / 内在损耗 / 暴露程度 / 身份记录 / 异化状态 / 血统认知 / 当前状态 / 圈内代号 |
| 单个角色 | `故事线进度` / 位阶传闻 / 位阶真实 / 玩家已知程度 / 与玩家的账 / 被掌握的底牌 / 圈内代号 / 已接触 |
| 世界 | 日期 / 事件线（**上限 12 条**）/ 势力状态（管理局·家族·散人网·没落旧家）/ 当前引力源 / 结局进度 / 变量结构版本（**只有脚本能写，模型不写**） |

> **常见误填**：写"好感度""NPC 当前位置""他的心情"。**这三个骨架里都没有**，也不打算加（`骨架说明.md` §五 解释了为什么）。

### 3.4 为什么格式要求这么死

因为故事线要**按需注入**——不能整条线塞进提示词。

落地计划（**属于机制层，Agent 负责，你只需知道**）：每条故事线会按「**角色真名 + 该步标记**」切成世界书条目。模型只在轮到这一步时看到这一步的内容。

**这就是"标记必须写成统一格式"的真正原因**：格式不统一，切不出条目，整条线就只能整篇进提示词——那会长期占额度并稀释模型注意力（对应 `NEXT.md` 开放风险第 3、4 条）。
