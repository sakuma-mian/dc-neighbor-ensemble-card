## 一、本阶要解决什么

第 1 阶冻结了 D-010「异能本质 = 觉醒来源 + 代价绑定 + **明示战力制** + 高代价成长 + 灰色基调」，其中"刻度层"要求：**存在明显的战力体系，强弱可以用稳定刻度描述，不靠"他很强"这种模糊话。**

但第 4 阶落地完 58 个字段之后，露出了一个空洞：

> 掌控度、承载上限、位阶这三样东西**彼此之间没有任何换算关系**。
> 模型每轮判断"这个人打不打得过那个人"，只能自由发挥。

**后果**：同一个人在两楼里可能判出两个强度；越写越离谱；D-010 想兑现的"明显的战力体系"实际上没落地，只落了五个黑话标签。

本阶要把这个空洞填上：给模型一把**稳定、不会前后漂移**的尺子，同时**不让数字进叙事**。

### 我的思考链（含被否决的路）

**第一，我先判定"明示战力制"和"实测数据会骗人"并不矛盾，而且你已冻结的条款恰好提供了必需的零件。**

普通做法是"位阶公开、按等级排座次"，那博弈就变成比大小，第 1 阶定的"人际纵横捭阖"会落空。但既然 C-09 已经规定了**同类感应**（强者能感知弱者，反之不行），圈内的"测量"就天然是一种**带误差的读数**，而不是权威证书。于是：

> **可测量的刻度 + 可被隐瞒的读数 + 会出错的观察者 = 明示但不透明。**

这条等式是本阶全部设计的地基。

**第二，我否决了"单一数字走到底"。** 一开始最省事的方案是只记一个战力值，位阶由它推导。但这个方案会立刻穿帮：某人重伤倒地后位阶跌成"不入流"，两天后又"恢复"成"高位"——**名声不会因为你今天发烧就掉档**。所以必须三层分开：本体强度（极少变）、当轮战力（每场重算、不存字段）、位阶（社会评价、会滞后）。

**第三，我否决了"把异能能力直接加成持久数值"。** 你提的公式里有一项"异能能力（比如持续性战力提升）"，最直觉的做法是给能力一个固定强度分。但这与第 1 阶冻结的那句"**能力本质不进入刻度**"直接冲突，还会引出"控火 3 分 + 控水 5 分"这种荒唐问题。改成 **"战力修正"（战斗力怎么变）而不是"能力强度"（能力值几分）**，并且**只在当场生效、不写回基础战斗力**——冲突消失，你要的效果还在。

**第四，我否决了"排行系统"。** 你提出"战力位阶也可以叫战斗力排行"，我按最直观的解法推演了一遍，发现三处硬伤：

1. 圈内只有几百人、严格隐瞒，**没有公开榜单可以存在**；
2. 会与 D-013「实测数据会骗人／藏级是常规手段」互相拆台——有精确名次就不需要验牌了；
3. 我给的补救方案（"圈内私下流传的过时榜单"）确实能立住，但那会让"情报商人"变成一个必建的实体，**属于范围扩张**。

所以我在提案里把它标成待决而非默认加入。**你随后决定砍掉——这是本阶最干净的一次减法。**

**第五，我把"数值膨胀"从"乘 10"改成了"乘 10 并加深结构"。** 你要求"统一膨胀几倍，让战力系统有更大的操作空间"。但如果只是把所有数字 ×10，碾压门槛从 20 变 200、档位宽度从 20 变 200、掌控度还是 6 个格——**数字变大了，玩家能做的选择一个没多**，属于数值虚胖。真正的操作空间来自三件事：

| 来源 | 具体做法 |
|---|---|
| 刻度分辨率 | 掌控／承载从 0–5 扩到 **0–10**（6 格 → 11 格） |
| 单项权重 | 一点掌控 = **50 分**（原来 5 分），"练出半级"能被看见 |
| 层次数量 | 异化分三级（+100／+200），高分段从空变成满 |

**第六，我主动加了四条"防失控闸门"，因为数值放大 10 倍之后模型写错的误差也放大 10 倍。** 最重要的一条是：**所有临场修正之和不得超过基础战斗力的 50%**——它保证了没有任何单一因素能凭空造出一整档，从而守住"实力本身才是硬道理"。

**第七，关于武器，我做了两处设定级判断。**

- **物理武器不违反 C-11**。你冻结的是"异能不留物理痕迹"，而枪械刀剑**本来就留物理痕迹**。两者是互补而非冲突：**异能留感知痕迹，物理武器留物理痕迹；一个异能者用枪，是用一种留痕换掉另一种留痕。** 这还顺带让"异能者对普通人的恐惧"和"异能者必须隐瞒"同时立得住——异能者不是超人。
- **"普通人拿特殊材料武器没用"这条必须写死**，否则武器就变成实力的替代品，整条战力链会被"谁拿到神器谁最强"劫持。武器是杠杆，不是发动机。

**第八，缴械机制是我主动加的，你随后确认。** 不加它，武器就是白送的分。加了之后形成两种真实的战术风格（武者型 / 术者型），而且**缴械本身是弱者的一条合法翻盘路径**——正好落在"三个例外"的 (a) 项里。

### 被否决／未采纳的路（留档，避免以后重走）

| 方案 | 否决理由 |
|---|---|

## 三、正式设计（施工依据）

### 3.1 三层结构

| 层 | 名称 | 回答什么 | 更新频率 | 是否进变量 |
|---|---|---|---|---|
| 本体 | **基础战斗力** | 他有多强 | 极少（只靠跃迁） | ✅ 玩家侧一个数字 |
| 临场 | **当轮战力** | 他**这一场**打得怎么样 | 每场重算 | ❌ 不存 |
| 社会 | **位阶** | 别人以为他多强 | 滞后于真实水平 | ✅ 位阶三件套（已有） |

**父子关系**：位阶由基础战斗力映射而来，当轮战力以基础战斗力为底再叠加修正。

### 3.2 基础战斗力与档位

```
基础战斗力 = 掌控度 × 50  +  承载上限 × 50  +  异化修正  +  血统加成
```

| 项 | 范围 | 说明 |
|---|---|---|
| 掌控度 × 50 | 0–500 | 用得有多精细 |
| 承载上限 × 50 | 0–500 | 能压多大 |
| 异化修正 | 0 / +100 / +200 | 未涉足 / 进行中 / 已异化（三级，与 `/玩家/异化状态` 的枚举一一对应） |
| 血统加成 | 0 / +100 / +200（**待定，首版记 0**） | 等驾驶员写血统体系后定 |
| 理论上限 | 约 1300 | 掌控10 + 承载10 + 异化 + 高血统 |

**档位对照表**（沿用第 1 阶冻结的五个词，只重划数值边界）：

| 黑话 | 基础战斗力 | 这个水平什么样 | 全城大概几人 |
|---|---|---|---|
| **不入流** | 0–199 | 刚觉醒，出手就亏本 | 大部分新人 |
| **中游** | 200–399 | 能打，压不住场 | 圈内主力 |
| **高位** | 400–599 | 能自己开一局 | 几十人 |
| **传闻极强** | 600–799 | 全城数得出来 | 十几人 |
| **深不可测** | 800–1300 | 出手就是大事 | 三到五人 |

> **800 分以上一律不表态**：圈内人只会说"别去惹"，不会说出任何具体数值。这既是设定味道，也防止模型在高分段乱写数字。

**玩家成长线**（这是"操作空间"的实际体现）：

| 阶段 | 掌控 + 承载 | 基础战斗力 |
|---|---|---|
| 开局（刚觉醒） | 1 + 1 | **100** |
| 能自保（约一季剧情） | 2 + 2 | **200** |
| 有点名气 | 3 + 3 | **300** |
| 圈内中坚 | 4 + 4 | **400** |
| 走完一条完整故事线 | 5 + 5 | **500** |
| 靠"逼"和"悟"续命 | 7 + 7 | **700** |
| 天花板（理论） | 10 + 10 | **1000** |

**成长闸门（D-056）**：

| 单项 | 成长方式 |
|---|---|
| 0 → 4 | **磨**（场地 + 时间 + 安全即可） |
| 4 → 8 | 只能 **逼**（生死边缘、强敌压迫、被逼到绝境） |
| 8 → 10 | 只能 **悟**（剧情事件：想通自身能力的本质） |

大白话：**能自己偷偷练上去的只有 200 分**；再往上必须把命押出去。

**跃迁幅度与封顶**：

| 类型 | 数值 | 代价（写进 `/玩家/当前状态`） |
|---|---|---|
| 磨 | +50 | 内在损耗上升 + 暴露程度上升 |
| 逼 | +90 | 必然受伤 + 事件线留痕 |
| 悟 | +150 | 需要驾驶员给的线索触发 |
| **封顶** | 500 分前单次 ≤ +200；500–700 单次 ≤ +90；700 以上单次 ≤ +50 | — |
| 间隔 | 两次跃迁之间至少隔一次完整休整 | — |

### 3.3 当轮战力方程（战斗评定用）

```
当轮战力 = 基础战斗力              掌控×50 + 承载×50 + 异化 + 血统
         + 异能修正                增幅／爆发／干涉／信息（异化不在此项）
         + 武器加成                媒介 +100 ／ 物理 +50 ／ 混合 +150（三选一）
         + 环境修正                场地／遮蔽／目击者
         + 战斗表现                先手／奇招／识破／冒险／被拖节奏
         + 状态修正                损耗／带伤／准备／被偷袭
         −  缴械惩罚               −100 ~ −150（依赖武器者才吃）
```

#### 异能修正（D-061）

| 形态 | 战斗中的表现 | 修正 |
|---|---|---|
| **增幅型** | 越打越强 | 每回合 **+30**，上限 +150；内在损耗加速 |
| **爆发型** | 一口气打空 | 单回合 **+150~250**，之后一回合 **−200** |
| **信息型** | 不直接动手 | 不改变数字，改变"**情报**"这项定性因素 |
| **干涉型** | 控场、限制、偷取 | 不减自己，**减对方 −100~−200** |
| **异化型** | 突破常规 | **不在此处计算**（已计入基础战斗力的异化修正） |

#### 状态修正

| 状态 | 修正 | 说明 |
|---|---|---|
| 内在损耗 0–39 | 无 | 常态 |
| 内在损耗 40–69 | **−100** | 掉半档，出手发虚 |
| 内在损耗 70–89 | **−250** | 掉一整档，命在抖 |
| 内在损耗 90–100 | 基本不能战 | 再动就是自伤 |
| 带伤（`/玩家/当前状态`） | **−100 ~ −300** | 模型按伤势位置判 |
| 充分准备（设伏、选场地） | **+100** | "准备"兑现的地方 |
| 被偷袭 / 措手不及 | **−150** | "情报"兑现的地方 |

#### 战场环境

| 环境 | 修正 |
|---|---|
| 狭窄 / 室内 | 范围型异能受限 **−100** |
| 开阔 / 大街 | 逃得掉，弱者更容易抽身 |
| 夜间 / 遮蔽多 | 暗伤类、速度类 **+50** |
| 人多（闹市 / 咖啡厅） | 双方 **−100**，且暴露风险暴增 |
| 有易燃 / 可破坏物 | 环境本身成为武器 |
| **无人处** | 无修正，但**没有目击者 = 暴露不涨** |

#### 战斗表现

| 动作 | 修正 |
|---|---|
| 抢到先手 | **+50** |
| 打出对方没料到的招 | **+50** |
| 战斗中识破对方套路 | **+50** |
| 冒险一搏（赌一把） | **+100**，失败时受伤加重 |
| 被拖入对方节奏（被迫防守） | **−100** |

#### 武器（D-058 ~ D-060）

**两类武器**：

| 类型 | 性质 | 对异能者 | 暴露程度 |
|---|---|---|---|
| **物理武器**（枪械、刀剑、钝器） | 真实物理伤害——**异能者也会流血** | +50（有异能根基者） | **明显上升**（枪声、血迹、弹壳都是真痕迹） |
| **特殊材料武器**（现实中不存在的材质） | 能伤到靠异能护体的人 | +150 | **不涨**（本身无异能痕迹） |

**三种用法（三选一，不许叠加）**：

| 用法 | 加成 | 代价 |
|---|---|---|
| **媒介**（异能通过武器释放） | **+100** | 无额外暴露 |
| **纯物理**（直接砍、开枪，不叠异能） | **+50** | 暴露明显上升 |
| **混合**（异能 + 武器同时用） | **+150** | 暴露上升 + 损耗加速 |

**两条铁律**：

1. **武器不放大异能，只集中异能。**不是"有刀就多 150 分"，而是"有刀，那 150 分的力量能精准打在一个点上"。
2. **没有异能根基的人拿特殊材料武器没有任何加成**——那只是一块怪铁。武器是杠杆，不是发动机。

**武器在不同强度层的作用**：

| 强度区间 | 武器的作用 |
|---|---|
| 0–199（不入流） | **决定性**——武器能让你打赢同龄人 |
| 200–399（中游） | **重要**——能左右同档胜负，但跨不过 200 分天堑 |
| 400–599（高位） | **次要**——只改变细节 |
| 600+ | 几乎无用，除非那一两件特殊材料武器 |

**缴械机制（D-060）**：

| 情况 | 后果 |
|---|---|
| 纯物理武器者被打掉武器 | **−150**，且本回合失去武器带来的战术选项 |
| 媒介型被打掉武器 | **−100** |
| 混合用法被打掉武器 | **−100**，但异能本身仍在（不会失去异能） |
| 纯异能者（不用武器） | 无惩罚，**但也没有武器加成** |
| 特殊材料武器被夺 | 夺走者**未必能用**——没有异能根基，那只是块怪铁 |

### 3.4 感应读数协议（D-022 / C-09 的机制化）

设 A 为感应者、B 为被感应者：

| 强度差 | 感应结果 |
|---|---|
| B 强 A 200+ | **完全感应不到** |
| B 强 A 50–200 | 模糊压迫感，判不出档位 |
| 差距 50 以内 | "跟我差不多"，分不出高下 |
| A 强 B 50–200 | "他比我弱一档" |
| A 强 B 200–400 | "他比我弱两档，能摸到底" |
| A 强 B 400+ | "一眼看穿" |

> **核心限制：感应只读得出"量"，读不出"质"。**
> 你能感觉到他是个硬手，但**不知道他是什么能力**。这条让"我打不过他"和"我不知道他会干什么"同时成立——底牌悬念得以保留。

### 3.5 战斗评定流程（五步）

**第 0 步 · 铁律**：只有在基础战斗力差 **200 分以内**，状态与情境才能翻转胜负；超过 200 分就是碾压，弱者要赢必须动用三个例外。

**第 1 步 · 取双方基础战斗力**（玩家按公式算；NPC 读 `/角色/{名}/位阶真实` 对应档位的中值）

**第 2 步 · 加状态修正** → 得"当轮战力"

**第 3 步 · 感应判定**（决定玩家能读到什么，见 3.4）

**第 4 步 · 判定**：

| 当轮战力差 | 结果 |
|---|---|
| **> 200** | **碾压**。弱者只能逃、只能被拿捏 |
| **50–200** | **单方面占优**。强者能决定走向，弱者能脱身并付出代价伤到对方 |
| **< 50** | **同档缠斗**。看下面五个定性因素，胜负不定，双方都流血 |

**第 5 步 · 定代价**：

| 战况 | 赢的一方付什么 |
|---|---|
| 碾压（>200） | 几乎无损，但**出手本身抬暴露程度** |
| 占优（50–200） | 内在损耗中量 + 暴露程度抬 |
| 缠斗（<50） | 两败俱伤，可能有不可逆损伤 |
| 越级胜 | **付出不可逆的代价**：重伤、异化推进、暴露自己 |

### 3.6 同档内胜负的五个定性因素

相性 / 情报 / 准备 / 代价意愿 / 第三方——**这五项不进刻度**，只做叙事判断。

> **硬约束**：相性只能决定"同档内"的胜负细节，**绝不能用来跨越 200 分的差距**。
> 例：一个中游预知者对上高位强者，可以躲、可以逃、可以拖、可以先跑掉，但**不可能正面打赢**。

### 3.7 三个例外（弱者翻盘的唯一合法通路）

> 分数低的人要赢分数高的人，**必须**满足三者之一：
> **(a) 提前布了局**（场地、陷阱、盟友、时间）
> **(b) 付出了不可逆的代价**（异化推进、重伤、暴露自己）
> **(c) 第三方在场改变了局面**

三者都不满足，**不许出现以弱胜强**。每一次越级获胜都会成为事件线里的一件事。

### 3.8 四条防失控闸门

1. **单次跃迁封顶**：500 分前 ≤ +200；500–700 ≤ +90；700 以上 ≤ +50。
2. **临场修正之和 ≤ 基础战斗力的 50%**——没有任何单一因素能凭空造出一整档。
3. **武器只算一处**（媒介／物理／混合三选一），不许叠加。
4. **环境与"准备"互斥**：场地是当场选的按环境算，提前布好的按准备算，**不能两头吃**。

### 3.9 一句话概括

> **刻度只管量，不管质；战力比较定"基本态势"，情境因素定"例外"；例外必须用事件解释。**
