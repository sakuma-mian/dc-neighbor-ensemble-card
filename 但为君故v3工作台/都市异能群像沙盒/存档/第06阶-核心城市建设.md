## 一、本轮要解决什么

第 02 阶把城市主创权交给驾驶员（D-028），第 04 阶备好了 `设定/城市模板.md` 空表，此后一直挂着三个待办。本阶段解决其中最大的一个：

> **把一座城市从零建出来，并且让它能接住开局匹配算法（D-036）。**

具体要产出四样东西：

1. 一座有名字、有六区、有社会切面、有势力落点的城市；
2. 十处**具体到"在那儿能发生什么"**的关键地点（模板硬性要求 6–10 处，且必须写明玩家用途）；
3. 一个能喂进开局算法的**开局时间点与近期事件**；
4. 两位已定稿核心角色（藤原花奈、顾清寒）各自的生活片区。

另外顺手结掉一个从第 01 阶挂到现在的遗留项：**D-018「是否存在屏蔽感应的手段」**——第 01 阶说"第 2 阶势力结构时一起定"，第 02 阶当时在谈管理局性质与家族格局，把它漏掉了。

## 二、我的思考链

### 1. 先定顺序，再动笔

驾驶员选的是「**严格按城市模板顺序走**」（一、城市基础 → 五、时间与开场）。这个选择是对的，理由不是流程好看，而是**依赖关系确实是从上到下的**：城市名决定全部地名的风格，社会切面决定势力能怎么落，势力落点决定关键地点长在哪。反过来做，每一格都会被上面一格推翻一次。

### 2. 命名法是这一轮真正的技术活

第一稿的难点不是取名字，是**取名字这件事本身要有规矩**。驾驶员最初给的六个区名是混的：江南、南江、北湾、临港带三点水，云间、普陀不带。

我没有逐个取新名，而是先立了一条法：**六个区名一律三点水开头，跟城市名「南江」同族。** 这是从驾驶员自己的直觉里推出来的（他原名里就有四个带水的），但一旦立成规矩，后面所有地名——湖、桥、街区——都自动有了生成规则，模型也不会写串。

这条法的收益在本阶段后面反复兑现：云渚湖、澜川大桥、汇水、汐湾，全是从它派生出来的，一个都不用另外想。

### 3. 被否决的路（记下来，避免以后重走）

| 走过的路 | 结果 |
|---|---|
| 城市名候选「澜浦市」／「浦川市」／「江城市」 | **未采纳**。驾驶员自定「南江市」——比三个候选都好，因为它自带"因江得名"的结构，直接给主江留了名字 |
| 区名「望海」（给东岸新城） | **废弃**。查证发现唐代真设过望海县，换成「潮川」 |
| 湖名「涟湖」「泮湖」 | **废弃**。两个都是真实湖泊名（天津有泮湖公园）。改用「云渚湖」——由自造区名派生，从根上不可能撞 |
| 巷名「书市巷」 | **改用通名「书市」**（书市巷是真实巷名） |
| 安全屋最初想设在云渚湖心岛 | **改址到老坑**。湖心岛已经是散人网藏身处，两个功能挤在一处会互相削弱；而矿坑改造的温室群是驾驶员初稿里现成的地标，缝进去更省 |
| 开局"大事"原提案＝旧织造厂坍塌＋六号院挂牌（一件已发生 + 一个时钟） | **驾驶员只留了挂牌**。我随后发现挂牌本身就能兼两职（两周前挂出去＝刚发生过；还没人摘牌＝时钟还在走），所以不必再加第二场事故 |
| 顾清寒原稿的「未成年」口径 | **已去掉**。驾驶员指示：18 岁成年 |
| 逐名查证公开地名以规避撞名 | **本阶段结束后停止**。驾驶员宣布：本城完全架空，撞名即巧合 |

### 4. 两处"从已定条件里长出来"的发现

这两条不是我加设定，是**把已有设定往下推了一步**，推完发现它们本来就在那儿：

- **感应钝化落在老坑**：第 01 阶要求"屏蔽感应的手段"必须稀缺，稀缺才值钱。而驾驶员初稿里正好有"由矿坑改造的花园景观"——一个坑底岩层够厚的废弃采石场，是全城唯一解释得通的地方。
- **顾清寒的"缝"**：城市模板定了「分层秩序」——澜浦是核心区、监控最密。而她的地盘恰恰在澜浦。看似矛盾，推下去发现真实城市正好相反：**新城监控全覆盖且互联，老城监控补丁式且互不联通**。所以新城更无处可藏，老城到处是缝。这条同时解释了她为什么更愿意待在老城、以及她五年没被发现。

### 5. 一条我自己差点写出的硬伤

上面那条"老城到处是缝"很漂亮，但**只对摄像头和人眼成立**。C-09 的同类感应是圈内雷达，它不看摄像头、不看巷子、不看有没有人。

如果照着写下去，就会得出"她在巷子里用能力不会被发现"——那是错的。所以我把它写死成一条口径，放进 `骨架/变量更新规则.txt` 与两份片区文档：

> **老城的"缝"只挡摄像头，挡不住同类感应。她五年没被发现，不是藏得好，是从未出手。**

### 6. 一个刻意的形状对照

两位核心角色的生活片区被我做成了**相反的两种形状**，这不是巧合：

| | 藤原花奈 · 云渚大学城 | 顾清寒 · 生活圈 |
|---|---|---|
| 形状 | **一片**（几百米内什么都齐） | **一条线**（每天跨江两趟，四小时在路上） |
| 半径 | 小，内容极密 | 大，内容极稀 |
| 为什么 | 被迫——本体必须在假体几百米内 | 被迫——被通勤拉扯 |

**两个人都被自己的处境画地为牢，只是牢的形状不一样。**
