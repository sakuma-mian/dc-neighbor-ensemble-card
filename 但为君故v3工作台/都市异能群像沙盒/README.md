## 一句话说明这个项目是什么

做一张 **SillyTavern 角色卡**：现代都市背景 + 异能存在 + 一群各自有算盘的 NPC + 没有固定主线，玩家随便怎么玩世界都接着跑。

## 存档规则（这是你要求的重点）

每推进一个**关键步骤**，我都会在 `存档/` 里留一份记录，结构固定：

```
第0N阶-<阶段名>.md
├── 本轮要解决什么      ← 目标
├── 我的思考链（中文）    ← 我怎么一步步推出来的，包括被否决的路
├── 关键决策与理由       ← 定了什么、为什么、代价是什么
├── 你的原话/选择        ← 你当时怎么说的，避免我以后脑补
└── 待决项与下一道门      ← 还没定的、下一步要问你什么
```

**为什么这么做**：AI 的对话记忆会丢，关掉窗口就等于没发生。只有写进文件的决定才算数。以后你说"我想改异能体系"，我翻 `存档/` 就知道当初为什么那样设计，不用你重新讲一遍历史。

## 术语对照（避免看不懂）

别担心，这些词第一次出现我都会用大白话解释。这里只备一份速查：

| 术语 | 大白话 | 本次项目里的意思 |
|---|---|---|
| **SillyTavern / ST** | 酒馆 | 跑角色卡的客户端软件，你的卡最终在这里面玩 |
| **角色卡** | 卡 | 一个能导入 ST 的设定包，含人设、世界书、开场白等 |
| **MVU** | 变量系统 | 让卡把"世界状态"真的记下来的机制——谁跟谁翻脸了、势力声望多少，不是靠模型临时编 |
| **世界书 / lorebook** | 设定集 | 按关键词触发注入给模型的背景资料，避免一次性塞爆提示词 |
| **群像** | 一屋子活人 | 多个 NPC 各自有目标、会自己行动、会互相算计，不是围着主角转的功能件 |
| **沙盒** | 开放式玩法 | 没有强制主线，玩家去哪、帮谁、摆烂都由玩家决定，世界照样运转 |
| **退出门** | 做完的标准 | 一个阶段满足哪些可验证的条件才算真做完 |
