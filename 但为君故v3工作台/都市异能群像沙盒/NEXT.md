### 世界观与异能（第 1 阶冻结，共 12 条施工条款）
- C-01 现代都市，异能存在但对大众严格隐瞒
- C-02 存在知情并管事的组织（半官方性质，见 D-022）
- C-03 全城异能者约几百人（千万人口量级）
- C-04 异能 = 血统定天赋与上限 + 极致刺激点火
- C-05 高血统者觉醒前与普通人无异（不可凭血统认人）
- C-06 能力本质固定；成长分常规（掌控度/承载上限）与异化（极少数质变）两路
- C-07 代价内外双收：伤自己 + 暴露风险随力量增长
- C-08 位阶圈内公开、大众不知，实测数据会骗人，藏级是常规手段
- C-09 暴露机制 = 同类感应（强者可感知弱者，反之不行）
- C-10 灰色基调：每个 NPC 一个站得住的理由 + 一件不可原谅的事
- C-11 本设定不含物理痕迹机制（用异能不会被摄像头/仪器拍到）
- C-12 玩家开局：刚觉醒、未被登记、血统不明

### 群像与势力（第 2 阶冻结）
- 权力结构 = 三足鼎立：管理局 / 血统家族 / 散人网
- 管理局 = 半官方（明面执法，暗地有算盘）
- 家族格局 = 三强一弱（三大族 + 一个没落旧家）
- 群像分层 = 核心 6–8 人 / 外围 20–30 人 / 背景数百人
- 命名 = 真名 + 圈内代号（圈内有黑话体系）
- 群像生成方法 = 从每势力内部矛盾反推 NPC（7 人配置）
- **主创权**：核心人设、城市建设、剧情线、结局 **全部由驾驶员提供**；Agent 只负责机制、容器格式、一致性检验与落地

### 自由度与叙事机制（第 3 阶冻结）
- 世界自转 = 伪流动架构（每核心角色一条隐藏主线剧情）
- 叙事结构 = 串珠式（人设决定开局 → 沿角色线深入 → 由此认识都市与他人 → 接下一条）
- 交织 = 涟漪式（NPC 动作在别处显出后果）
- 玩家介入 = 原生剧本优先 + 动态推演兜底
- 引导原则 = 引力而非轨道（无系统语言、可拒绝、不阻塞、每次接触都有剧情内理由）
- 世界可见度 = 隐性为底
- 时间 = 回合驱动 + 隐性时钟，可被玩家主动跳过
- 世界时钟精度 = 轻量（日期 + 事件线 + 故事线进度）
- 开局接口 = 匹配算法（主控人设 × 角色人设的性格/常驻地点/职业/过往 → 第一个接触者）
- 故事线运营 = 连载式更新 + 结局随版本推进

### 战力体系与战斗评定（第 5 阶冻结，共 15 条决定 D-048 ~ D-062）
- D-048 三层结构：本体强度（客观）/ 当轮战力（临场，不存字段）/ 位阶（社会评价）
- D-049 数字**只给玩家自己看**；NPC 一律用圈内黑话与区间
- D-050 成长 = **跃迁制**（平时不涨，只在关键事件跳，每次自带代价）
- D-051 **砍掉排行系统**；D-052 位阶保留（名声 ≠ 名次）
- D-053 基础战斗力 = **掌控度×50 + 承载上限×50 + 异化修正 + 血统加成**
- D-054 数值整体 **×10 膨胀**，掌控／承载值域 **0–5 → 0–10**
- D-055 档位边界 = **0 / 200 / 400 / 600 / 800**（沿用已冻结的五个黑话词）
- D-056 成长闸门：单项 **0→4 磨**、**4→8 逼**、**8→10 悟**（能自己练的只有 200 分）
- D-057 战斗判定 = 碾压（>200）/ 占优（50–200）/ 缠斗（<50），**不掷骰**
- D-058 武器两类：**物理武器**（异能者也会流血）+ **特殊材料武器**
- D-059 特殊武器**来源由驾驶员在人设时携带**，机制层不代填
- D-060 **缴械机制**（−100 ~ −150；纯异能者无惩罚但也无加成）
- D-061 异能修正五形态：增幅／爆发／干涉／信息／异化
- D-062 弱者翻盘**三个例外**：布了局 / 付了不可逆代价 / 第三方介入
- 感应读数：**只读得出"量"，读不出"质"**（知道你打不过他，但不知道他会干什么）
- 四条防失控闸门：单次跃迁封顶 / 临场修正 ≤ 基础战力 50% / 武器只算一处 / 环境与准备互斥

### MVU 变量链（2026-09-18 接线 · **待真机**）
> 完整解释见 `骨架/骨架说明.md` 第二节。以下结论全部来自**官方源码直读**（`bundle.js` 573 KB 全量下载后逐条比对）＋ 本机 CDN 实测，不是二手资料。

- **接线前的真实状态：五层里断了四层。** 规则条目在但标记写成全角；结构约束在但缺 `registerMvuSchema` 来源；本体脚本、初始变量条目、两条正则全无 —— **这套变量系统此前一次都没有真正运行过**。
