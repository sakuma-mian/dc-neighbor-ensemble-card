## 二、导入步骤

2. 导入**角色卡**：把 `输出/…v1.0.png`（或 .json）拖入酒馆角色导入，或用扩展导入。导入时酒馆助手会提示安装卡内 **4 个脚本**（MVU 加载器 / ZOD schema / R2 迷雾门卫 / 雾青前端渲染）——全部允许。
3. 卡自带**世界书**（`但为君故·世界书`，48 条）随卡挂载；世界书预算建议 ≥ 25%。
4. 选中角色 → **新开聊天**。

## 三、开局流程

1. 开场即「**创建你的身份**」创角页（雾青风界面）。
   仅 **DC 网名**与**年龄**（18~99，NSFW 内容边界）必填；住址为七项下拉（与初遇路由五轴对应）；留空字段记「未知」，不伪造。
2. 「写入并开始」→ 写入预览确认 → 提交。写入范围＝`user` 九字段＋`规则.初始化完成=true`（**创角页是全卡唯一变量写入口**，DEC-036）。
3. 「进入频道」→ 自动发送过场消息并触发第一轮剧情（走当前预设与剧情模型）。
4. 已写入过的存档再进创角页会直接显示完成态（幂等，不会重复采集）。

## 四、游玩界面

- **状态栏**：每条 AI 楼层下方自动渲染五人雾青状态栏（好感条/十二档关系阶段/迷雾珠/登场/环境时间）。变量更新后自动刷新。
- **群像页**：聊天右下角「◇」悬浮按钮 → 全屏群像（跳板卡 → 单人档案）。档案含双头像位：雾态＝DC 头像，**身份揭晓后自动切换立绘＋真名**（读 `关系.*.身份揭晓`，DEC-033）。
- **迷雾门控（R2）**：自动运行。任一知情者的迷雾格翻为「已揭示/误信已纠正」→ 对应秘密世界书词条解锁进场；新聊天/回溯自动复位。**请勿手改 stat_data**，会破坏门控一致性。
- 变量块 `<UpdateVariable>` 由卡内正则自动隐藏（渲染层）并从提示词历史剥离（R3）；MVU 框架读原始楼层，不受影响。

## 五、故障排查

| 症状 | 处置 |
|---|---|
| 开场显示一段代码而非界面 | 酒馆助手未装或 <4.8.4：安装/更新后重开聊天 |
| 无状态栏 / 提示 `Mvu 全局不可用` | MVU 加载失败：检查网络（jsDelivr），或看酒馆助手脚本面板里 MVU 脚本报错 |
| 变量不更新 | 预设未载入（更新规则/输出格式词条在卡世界书，需【状态更新】标记配合）；双模型模式检查更新模型连接 |
| 秘密词条一直不出现 | 正常——迷雾未揭开。R2 只在正文明确揭开场景翻格后解锁 |
| 群像页头像不显示 | data URI 内嵌，正常不应失败；若主题屏蔽 iframe 脚本请检查酒馆助手设置「允许前端渲染」 |
