## 1. 设计目标

场所层是城市层之下的第二级场景粒度：当剧情进入"南江大学"这个舞台时，为其提供**可步行的空间、可触摸的物件、可参与的活动**。对本卡有三个直接价值：

1. **花奈的主舞台**：她的学生身份绑定在此（DEC-016，路由裁定"南江大学降落的主控遇花奈概率最大"）——她的大多数日常戏需要一个可信的校园底座。
2. **主控可自由进出**：草案的"无围墙、无门禁"设定是剧情富矿——非学生的主控和其他角色可以随时自然地出现在校园里，无需编造入校理由。
3. **跨层呼应**：草案把研究所嵌进城市设施（法院/市图书馆新馆/人民医院总院/市民广场地下/湿地公园），与城市层 C0/C2 已收录的地点严丝合缝，两层数据互相背书。

## 4. 递归与预算策略（与城市层同构）

- U0 设 `Prevent further recursion`；U1-U5 设 `Non-recursable`。理由同城市层 README §4：U0 正文提及学院与地标，若允许递归会把子词条成串顶活；关闭递归让激活完全由聊天关键词决定，预算可预期。
- 各词条显式 `matchWholeWords=false`（CJK）、`caseSensitive=false`、`probability=100`、`sticky/cooldown/delay=0`、`scanDepth=null`（继承全局 ≥4）、`vectorized=false`。
- **预算估算**（定稿实测 713/582/214/691/493/666）：六条全开约 3360 字（中文 0.6-1.2 token/字 ≈ 2000-4000 token）；典型激活 U0+1~2 条 ≈ 950-1600 字。城市层+场所层极端同开约 7300 字，ACC-005 时须用真实 tokenizer 复核总账；若逼近预算优先压缩 U5/U3 的修辞段。
- 跨层防链已验证：U3 正文提及法院/市图书馆新馆/人民医院总院/市民广场/湿地公园等城市地点，但 C2 为 Non-recursable，不会反向顶活城市层词条——反之亦然。

## 6. 草案打磨建议（供修订参考，未写入词条）

1. **钟声频率**：草案"十二钟每逢整点由机械装置击响、声覆三公里"= 每小时全江北的噪声源，与宜居城区设定有张力。建议改"平日单钟报时；节庆、开学与毕业典礼十二钟齐鸣"——仪式感反而更强。若采纳，U1 需同步改写。
2. **在校生规模缺失**：建议定一个数（如 2.4-2.8 万），食堂/图书馆高峰的拥挤感、社团招新的规模感都靠它。
3. **宿舍门禁**：无围墙 ≠ 宿舍楼无门禁。草案未提；而深夜剧情（含花奈线）的可行性取决于此，建议明确（现实高校宿舍楼普遍 23-24 点门禁，刷卡的 That 也可作为剧情细节）。
4. **校内医疗点**：草案未提校医院/医务室。若花奈"长期特效药"线需要校内取药场景，可在草案定稿+她的绑定信息明确后，于场所层补一条小词条（新 CLM，不入本轮）。
5. **三十万枚铜书签的体量**：壮观但如果进剧情（比如找某一枚），需注意"数十万枚中找一枚"的现实难度——这本身可以是剧情点。
