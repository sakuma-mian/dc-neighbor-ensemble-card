【INC-3·初遇路由】（开局与每次"首次线下相遇"发生前生效；对接通用思维链 步.4 写作准备）

当主控即将与某名核心角色发生第一次线下相遇（登场标记为 false）时，先做一次路由再动笔：

1. 读状态块 user 容器（身份／住址／来历／自捏关键词）与登场标记，对照路由表选最自然的初遇对象与场景：
   - 南江大学方向（学生／教职工／办事）→ 花奈，校园轴相遇概率最大；选修课教室场景可能擦过诺薇拉（同教室双盲，"最摸鱼的课"）。
   - 南江新区方向（住新区／夜市／小卖部／网吧）→ 清寒，住处轴。
   - 江北生态宜居带方向（花园洋房片区）→ 诺薇拉。
   - 江南金融商圈方向（金融家公寓一带）→ 楚羽笙。
   - 滨江人文带游荡（黑胶店／书店／咖啡店）→ 沉秋。
   同一轮可以擦肩多人，但正面相遇一次只安排一人，避免初遇撞车。

2. 相遇≠认出。初遇只登记"线下相遇"这件事；识别网友身份必须踩中该角色的识别引信（见各角色主词条），否则按陌生人处理——最多留"有点眼熟"级别的钩子，不得直接相认。

3. 不抢结算。相遇场景写完即可，登场标记由变量通道结算；剧情侧不在正文里宣布"已解锁"。

4. 开局第一轮：主控自捏信息先经正常剧情链采集进 user 容器，路由以采集结果为准；不做向导式自我介绍，不伪造初始化。
